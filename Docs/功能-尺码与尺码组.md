## 档案与规则
- 尺码（Size）：编码、名称必填，英文名称、类型标签、排序、备注可选；类型标签名称显示在尺码主列表；系统配置可设置新增编码自动生成开关、前缀和数字位数（默认 SZ + 不足四位左补零，如 SZ0001）；自动编码按当前占用情况分配最小可用序号，删除记录后序号可复用，尺码表为空时从 1 重新开始；关闭自动生成时新增需手填编码；编码可在尺码编辑时修改且不可重复；规则只影响新建记录，数据库主键仍独立递增。
- 尺码组（Size Group）：名称必填，新增时按系统参数中独立配置的自动编码规则生成编号（默认 SG + 不足四位左补零，如 SG0001），支持开关、前缀和数字位数；按当前占用编号分配最小可用号，删除后可复用，关闭自动生成时可手动填写；类型标签、排序、备注可选；至少一个尺码，明细有独立顺序，同组禁止重复ID或同名尺码；尺码组可删除并清理组内明细和标签关联。
- 尺码组编辑时通过弹窗表格搜索并多选尺码；确认后保留已有尺码顺序，新加入项追加至末尾。表单中可继续上移、下移或移除已选尺码。
- 不内置尺码、尺码组和类型标签。标签归属首次使用时按通用标签机制登记。
- 停用尺码不能新加入组，已在原组中的停用尺码允许保留、移除及调整顺序。未保存的新组不得引用停用尺码。
- 支持删除：尺码被任何尺码组引用时拒绝删除并提示先解除引用；未被引用的尺码可删除，删除后该编码序号重新成为可用号。尺码组删除时在同一事务内清理组内明细及标签关联，并记录审计日志。既有编码保持不变，新建记录按当前占用编码分配最小可用号。
- 后续样衣选择尺码组，再确定实际样衣尺码；业务保存尺码名称、顺序快照。样衣与快照逻辑留待样衣模块实现。

## 接口与权限
- /system/size-data/size、/system/size-data/size-group：POST新增，PUT /{id}编辑，PUT /{id}/status启停，DELETE /{id}删除，GET /list管理查询，GET /options登录业务选择；尺码支持 POST /batch-tags 批量替换类型标签。
- system:size:list/add/edit/delete、system:size-group:list/add/edit/delete。角色管理从 sys_menu 读取这些权限；普通角色需要管理员授权。
- PostgreSQL：sys_size、sys_size_group、sys_size_group_item；表及字段均有注释，主从保存使用事务，组内ID及排序有唯一约束。
- 新部署执行主建表脚本，旧环境执行 sql/尺码与尺码组_20261103.sql；已建环境补删除权限时执行 sql/尺码删除与短编码升级_20261104.sql。
- 可执行 sql/尺码自动编码规则_20261104.sql 预置尺码与尺码组编码参数；若尺码组规则缺失，也可直接在系统参数页保存默认值，由后端创建参数记录。
