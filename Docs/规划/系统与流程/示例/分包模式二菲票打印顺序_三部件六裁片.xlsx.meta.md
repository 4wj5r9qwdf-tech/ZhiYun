# 分包模式二菲票打印顺序示例工作簿

该工作簿用于解释菲票的打印遍历顺序，不作为生产标签、真实款式裁片名称或实际包码数据。

## 工作表内容

- `模式二打印路线`：先按尺码配比位分组，再按卷号和层数沿Y序向下；每个卷层位置按①到⑥横向列出六张裁片菲票。
- `模式二打印顺序`：324张示例菲票的逐张顺序，附每张演示用的唯一包码。
- `扎号矩阵`：展示固定的配比位与Y序扎号映射。
- `打印流程图`：展示模式二的循环和打印步骤。
- `原始手绘截图`：保留用户提供的原图；原图中2个部件、4个裁片仅作为原始讲解示意，统一示例按3个部件、6个裁片计算。

## 底层扎号规则

扎号由尺码配比位序和Y序固定映射：`（配比位序 - 1）× 9 + Y序`。例如S码第1个配比位的Y01到Y09为001到009；S码第2个配比位从010继续。所有打印模式共用该规则，改变模式只改变菲票的打印顺序。

六张裁片菲票在同一配比位和同一卷层位置使用相同扎号；每张实体菲票仍使用各自唯一的包码。`A/B/C`、`A1/A2`等名称和`PKG`编号均为示例值。
