# 规划文档

本目录集中保存织云 ERP 的系统、模块和专项功能规划。每项业务规则仍以对应的唯一规划文档为准，移动文档不改变原有业务含义。

## 目录分类

- [`系统与流程/`](系统与流程/)：系统需求、服装生产流程、整体开发路线和跨域实施计划。
- [`模块/`](模块/)：按业务模块维护职责、流程、字段和模块间边界，文件名统一使用 `模块-<模块名>.md`。
- [`专项功能/`](专项功能/)：尚未形成独立业务模块的专项功能规划与跨模块能力设计。

## 文档边界

- 本目录说明“系统/模块/功能计划建设什么、业务规则是什么”。
- [`../功能任务/`](../功能任务/) 保存已进入具体实施阶段的单功能任务、共享契约、负责人和验收记录，不作为长期规划文档的替代品。
- [`../功能实现状态.md`](../项目记录/功能实现状态.md) 记录当前实现与验收状态；规划文件不能单独证明功能已实现或验收。
- 技术规范、API/MCP 契约、测试验收、版本与开发日志继续由 `Docs/` 对应目录和索引维护。

新规划按上面类别放置，并在 [`../AI/项目上下文索引.md`](../AI/项目上下文索引.md) 保持导航有效；修改规划时同步更新相关模块、任务和索引引用。
