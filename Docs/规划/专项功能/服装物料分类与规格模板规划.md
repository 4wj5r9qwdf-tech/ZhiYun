# 服装物料分类与规格模板规划

首期已接入物料表单，供业务验收。模板目录使用预置定义，模板配置页面仍在规划中。物料档案直接选择可选的规格模板。字段及必填规则是织云的建议配置，实施时对照工厂实际样品确认。

## 一、物料范围和建议字段

按采购、备料、领用和盘点能否识别同一实物来设计规格。表中的字段供配置模板时选用。

| 分组 | 物料举例 | 优先维护的规格 | 按需补充 |
|---|---|---|---|
| 面料 / 里布 | 梭织、针织、罗纹、网布、口袋布、里布 | 织法 / 布面结构、成分及比例、克重（g/m²）、幅宽（cm）、经向与纬向标准缩率、缩率测试条件、密度及口径 | 幅宽口径（全幅或有效幅宽）、纱支及体系、后整理 |
| 衬料与填充 | 有纺衬、无纺衬、粘合衬、铺棉、填充纤维、肩垫 | 衬料结构、是否带胶、材质、克重或厚度；肩垫用尺寸和厚度 | 粘合衬供应商工艺建议及资料版本；填充料形态 |
| 缝制与装饰线 | 平缝线、包缝线、绣花线、弹力线 | 线材成分、线结构、线号及编号体系 | 公称每筒长度、供应商品号、特殊整理 |
| 拉链与粘扣带 | 尼龙、树脂、金属、隐形拉链，魔术贴 | 拉链牙型、号数、长度（mm）、开尾或闭尾、拉头类型；粘扣带用钩面或毛面、宽度 | 拉头锁止、左右插、布带色与牙色；粘扣带背胶 |
| 扣件与五金 | 钮扣、四合扣、揿扣、鸡眼、铆钉、D 形环、调节扣、绳扣 | 结构、材质、直径或内径（mm）；钮扣孔数、调节扣适配带宽 | 表面处理、五金配套部件、颜色或镀色 |
| 弹性材料与绳带 | 松紧带、抽绳、织带、包边带、反光带、防水压胶条 | 宽度或直径（mm）、截面或结构、材质、弹性类别 | 伸长率及测试条件、绳头形式、功能等级及规格书 |
| 商标与装饰件 | 主唛、尺码唛、洗水唛、织唛、吊牌、热转印标、章仔、亮片 | 用途、制作方式、成品尺寸（mm）、底材；唛标增加折法和固定方式 | 印刷稿版本、客户专用标识、吊孔位置；定版尺码内容 |
| 包装容器 | 外箱、内盒、纸袋、塑料袋、自封袋 | 纸箱内长宽高（mm）、纸板层数、楞型；袋宽、袋长（mm）、底褶或侧褶宽 | 纸箱外尺寸、纸袋纸张克重、提手类型、塑料袋膜厚（μm）、封口方式、袋长是否含封口舌 |
| 包装配件 | 衣架、吊粒、拷贝纸、隔板、胶带、打包带、贴纸、干燥剂 | 衣架宽度及类型、纸品长宽及克重、胶带宽度与公称长度、贴纸尺寸及基材、干燥剂每包净重 | 衣架钩型、胶带胶型、标签底纸和卷向 |
| 裁剪与缝制耗材 | 裁床纸、裁床膜、裁刀片、机针、画粉 | 纸膜宽度与厚度或克重、刀片尺寸及适配设备、机针针系统／针号／针尖类型 | 设备兼容清单或说明书 |
| 印绣、整烫与检验耗材 | 绣花衬纸、水溶膜、热转印纸、碳带、烫台布、清洁剂、去渍剂、润滑油 | 幅宽、厚度或克重、适配设备、成品规格；化学品记录产品型号及包装净含量 | 储存条件、供应商安全资料；批号和实际有效期记入来料批次 |

成衣用料和包装件可按需要进入款式 BOM 或包装方案。机针、裁床纸、清洁剂等车间耗材共用物料档案，可由车间领用单管理。设备本体和需要逐件追踪的资产通过设备资产档案管理。

面料和里布共用一套规格模板，成衣用途按所属分类或款式用料区分。「织法 / 布面结构」可填梭织平纹、梭织斜纹、针织罗纹等示例。标准缩率按经向和纬向分开记录，并注明洗涤、烘干等测试条件；负值表示尺寸增长。密度按供应商或检验资料的原口径填写：梭织记录经密、纬密，针织记录横列、纵行密度，并注明计数长度，避免不同织物用同一单位产生误读。衬布用于领口、袖口、门襟等部位定型或加固，单独用「衬布（含粘合衬）」模板记录衬布类型和是否带胶。两套模板均可直接选择。

## 二、在物料档案中选择模板

1. 在物料档案的新增和编辑表单中提供「规格模板（选填）」。录入人员从启用的模板中选择一套，表单随即展开对应字段。留空时可用通用规格尺寸和备注建档。
2. 分类用于物料归类、查询和人员分类权限。模板用于确定录入字段，两项独立维护。同一模板可供不同分类的物料使用。物料保存所选模板及规格值，编辑时回显。更换分类仍使用原模板。
3. 字段定义包含稳定编码、名称、数据类型、计量口径、录入帮助、可选值和排序。首期支持文本、整数、精确小数、选项和是否。模板决定字段是否必填。只对工厂已确认会影响下单、验收或领用的字段启用必填。
4. 可复用含义相同的属性。用途不同的「内长」「外长」「拉链长度」分别定义，即使单位同为 mm。克重 g/m²、厚度 μm、线号 Tex 属于规格口径。每个物料选择一个库存单位，并可配置多个采购或生产领用单位。固定换算系数保存在该物料，允许箱→盒→个逐级参照；入库时该系数只作为默认值，可按实际到货修改系数或库存数量，不回写物料默认值。每卷长度不固定时选择按实际数量录入。布卷实际长度和卷余量由后续入库、领料业务记录，业务单据保存当时使用的数量及换算快照，不能用库存单位显示小数位静默舍入实际数量。
5. 新增表单显示通用资料和规格两部分。编码、名称、分类、型号、品牌、颜色、库存单位及辅助单位继续复用现有能力。模板值支持详情、列表按模板筛选和通过模板编码、字段对象导入导出。经常变化的描述性标记继续走标签。

## 三、不同业务记录的职责

| 位置 | 例子 |
|---|---|
| 物料主档 | 18 mm 四孔树脂扣、5 号闭尾 180 mm 拉链、某一内尺寸的纸箱 |
| 供应商物料资料 | 厂家货号、采购单位、最小起订量、交期、报价 |
| 收货批次或卷 | 来料批号、缸号、实收色号、实测幅宽、单卷长度、检验结果及实际有效期 |
| 款式 BOM 和工艺 | 物料用途及位置、单件用量、损耗、按款式颜色或尺码的用料对应、工艺确认值 |
| 包装方案 | 每箱装几件成衣、配码方式、箱唛内容和打印规则 |

影响采购、库存区分或领用互换的规格，应使用不同物料编码或明确受控的库存维度。颜色可在档案中多选，后续收货和领料按实际颜色记录。批次差异使用批次管理。供应商推荐粘合温度、压力和时间可随产品资料保存，正式生产设定由工艺确认。

## 四、历史兼容与开发顺序

1. 首批配置面料 / 里布、衬布（含粘合衬）、缝纫线、拉链、钮扣和扣件、松紧带与织带、唛标与吊牌、纸箱、纸袋、塑料袋模板，供录入时直接选择。
2. 已有克重、幅宽和成分继续回显。选择面料模板时，对应到同一组稳定字段并带出已有值。原有规格尺寸和备注原样保留。切换或清空模板时，保留共有字段的值，已填写且会移出当前表单的字段先提示确认并保留历史。
3. 发布后保留模板与字段变更记录。已使用的模板和字段可停用，旧档案保留回显。改变计量口径或业务含义时创建新定义，历史档案和单据继续可读。模板维护权限和人员分类可见范围分别校验。
4. 首批以真实物料验收表单、权限、筛选、导入导出和历史回显。随后根据仓库使用情况补齐包装配件、生产耗材与专项工艺资料。

## AI 与沙盘相关物料资料（2026-11-19，规划待设计）

在现有物料分类、规格模板和标签体系上，核对成分、幅宽、克重、颜色、适用工艺、损耗、采购周期、最小采购量、替代关系、质量及储存要求。面辅料标签用于描述和匹配，单位、规格、损耗和采购条件使用明确结构化记录并保留来源与版本。

订单需求按款式、BOM、规格及实际色码配套展开，结合库存、预留、待检、在途、客供和采购记录计算缺口；AI 不能根据相似名称推断替代物料或改动既定用量规则。


### 物料档案的标签分类

物料档案功能规划材料特征、适用工艺、采购属性和特殊储存要求等标签分类。标签用于筛选面辅料和辅助工艺匹配；成分、幅宽、克重、规格、单位、损耗、库存和采购条件由结构化资料维护。标签、物料分类和规格模板各司其职，不能以标签自动认定替代料。
