## 待你拍板的点
1. **缝纫工细分粒度**：车工/平车/拷边/冚车——是"车工"一个岗位就够（默认角色=缝制操作，机型只作记录），还是每台机型单独岗位+角色？我倾向**只建"车工"一个主岗，机型作为报工记录字段**，不拆角色。
2. **整烫工细分**：中烫/终烫并入"整烫工"一个岗（烫哪段作记录），还是分开？
3. **特种工序岗**（锁眼钉扣/剪线头/打枣）词库没单列，需补进词库"岗位类"。上挂/下挂不设岗位（吊挂上线是附带动作，见生产流程规划 15.15.2）。
4. **线上业务部**（抖音/国际站）做不做？代工为主的话这条线可先留空。
5. **数据范围默认规则**：一线工=本组/本线、组长=本组、车间主任=本车间、经理=本部门、厂长/超管=全厂；QC 与财务=全厂对应域。是否有例外？
