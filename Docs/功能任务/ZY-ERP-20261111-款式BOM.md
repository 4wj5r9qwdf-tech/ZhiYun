# 款式 BOM 一期实施计划

状态：一期前后端已实现，开发库已迁移，待用户验收。适用单款和套装，复用款式、物料、颜色、尺码和计量单位档案。

## 业务结构

BOM 独立页面选择款式；套装自动带出组成子款及每套件数，在同页分别编辑各子款 BOM。每行单件用量属于具体子款。合并生产按实际配套汇总，分开生产按子款计算，单独下单沿用该子款 BOM。订单或 PO 保存实际配色配码及版本快照，不把套装颜色尺码强行等同于各子款规格。

## 字段规划

- 资料头：款式、版本号、状态、版本说明、创建与修改人员时间；发布、历史与引用规则在实施时沿用项目技术资料契约。
- 子款层：子款 ID、款号、名称、所属类别、每套件数和排序；组成与件数须在使用版本时形成快照。
- 用料明细：物料 ID、物料名称和规格、用途/部位、计量单位、单件基准用量、适用范围、备注和排序；颜色、规格及单位需要保留可追溯的引用或快照。
- 颜色尺码差异：款式颜色、款式尺码、物料颜色、实际单件用量；允许只覆盖颜色、尺码或特定颜色尺码组合，未覆盖时使用基准值；冲突必须提示，具体优先顺序为颜色尺码组合、单维度、基准值，颜色与尺码单维度同时命中且值不一致时要求显式配置组合，禁止静默猜测。
- 物料颜色映射与用量差异分别维护：例如白色上衣用白色线、黑色上衣用黑色线，但 S 和 XL 用量不同。仅允许选择款式档案有效颜色尺码组合和物料允许的颜色。
- 损耗、审批发布状态及版本切换影响应在产品实现时明确界面和业务规则，避免未经确认改变计算口径。

## 数量计算与边界

需求按实际订单各子款颜色尺码数量乘对应单件用量计算；套装按每套件数和订购套数展开。按物料、颜色、规格和单位等维度汇总，保留子款来源。计量单位引用物料允许的单位和该物料自身换算设置，使用十进制计算，保留中间精度，仅在约定边界舍入。BOM 仅提供计划值，不改变物料档案换算系数或库存数量。

## 实施顺序与验收

1. 梳理现有款式规格、物料单位、分类权限、页面组件和审计能力，定义版本及权限契约。
2. 实现数据库、接口、版本与审计，限制无权访问的款式和物料。
3. 实现独立列表和编辑页面，套装按子款分组维护；支持基准用量、颜色映射及尺码差异。
4. 验证单款、两种套装生产方式、不同子款配码、颜色尺码覆盖冲突、精度和权限；用户验收后补齐 API、主建表、Skill、MCP、权限和日志收尾。

## 本批实施与验收计划

本批交付独立的款式 BOM、规格核对、用量试算。先建立草稿与发布版本，再用同一套规则覆盖校验和试算。套装在同页维护各子款单件用料和整套共用物料。用料位置用于区分同一子款的基准行及颜色尺码例外。具体色码优先于单一维度和通用规则，同等优先级冲突须补充交叉规则。

用料可选库存单位及物料档案中允许生产使用的辅助单位，固定或手填的单位换算系数与库存单位、物料显示信息随版本保存，试算汇总到库存单位。试算读取款式档案的当前规格，用于研发核对。后续订单应保存实际配套及引用版本，供生产使用。损耗、跨套装复用子款标准 BOM、正式订单算料和库存联动另行衔接。

验收时用一个单款核对通用、单尺码和指定组合用量，再用一个串色异码套装检查每套件数、共用包装以及子款明细与汇总。故意漏配或让单颜色与单尺码规则冲突，规格核对应给出具体问题，发布应拦截。发布后可查看和复制，原版保持只读。

开发验证：前端类型检查与构建、后端打包、开发库迁移和后端重启通过。开发库单款与套装均已通过登录后的接口核对，覆盖草稿、版本回读、规格核对、按件与按套试算、发布及发布后只读。两个临时 BOM 版本已清理。浏览器操作和普通角色授权待验收核对。

## 物料档案、部件与裁剪的衔接

- BOM 用料引用物料档案的稳定 ID。选料支持按档案分类、编码、名称和规格查找，选中后带出档案规格、可用物料颜色和库存单位。成衣配色尺码决定适用哪条规则，物料颜色从所选物料的可用颜色中选。需要更换物料时，在对应颜色尺码规则中另选档案。
- 物料档案分类用于查找物料，BOM 用料类型记录本款中的用途。同一档案可在不同用料行作不同用途。裁剪构成通过稳定用料位置关联 BOM，裁片自带部件归属。缝制工序可按需引用扣子、拉链和标识等用料，整套共用包装按套计。
- 新选或换料时校验物料、颜色、单位状态和分类权限。发布版保存物料 ID 以及当时的编码、名称、规格、颜色和单位供历史追溯。裁剪领料按解析出的物料和颜色查找实际可领批次或布卷，批次与实耗由执行单据登记。
- 当前一期已通过物料档案选料、引用物料 ID、校验可用颜色并带出库存单位。按分类筛选、独立用途类型、稳定用料位置及裁剪映射属于下一批衔接工作。

本批 BOM 改造增加用料类型、选料分类筛选和稳定的用料位置 ID。物料分类和规格由档案带出，新保存版本记录分类和规格快照。色码例外沿用位置 ID 与用料类型，改名不改变位置 ID。旧版按原来的子款和位置名称派生 ID，已发布版本继续可读；旧草稿或复制的新版本保存时须补选用料类型。当前分类筛选按物料档案归属的具体分类节点匹配。

录入简化后，表单和试算明细移除手填的用料位置。技术员直接选择用料类型和物料；复制色码例外时沿用用料行 ID，后续裁片映射可引用该 ID。旧版本保留已有名称用于兼容。

BOM 表单按款式档案的有效颜色尺码组合录入。套装分别显示各子款的组合，整套共用物料仍单独按套录入。可以把同一子款已配置规格的整组用料复制到当前规格，再修改物料和单件用量，覆盖已有用料前会确认。旧版本的通用和单维度规则继续生效，可在当前规格上单独调整。

2026-11-11 补充：编辑区左侧按子款列出有效颜色尺码，右侧维护当前规格用料；支持一次复制到多个目标规格，已有用料需要确认替换。物料颜色与规格来自所选档案，生产使用单位及换算系数在后端校验并按库存单位试算。

录入界面调整：物料分类筛选置于选择物料弹窗中，复用公共多选组件，支持按分类和编码、名称、规格搜索并跨筛选保留选择；确认后批量带入当前子款颜色尺码。每条用料的类型和用量由技术员填写，颜色与生产单位按该物料档案选择。

本款用途（面布、里布等）改为可选，物料的基础分类继续从物料档案带出。不同款式可能以不同方式使用同一物料，系统不依据分类自动猜测用途。裁剪功能接入时，对需要按用途筛选的任务提醒补齐相关用料的用途。

选料弹窗使用物料分类类型及分类层级树，点击上级包含下级物料，跨分类勾选保留；树与物料选项由现有权限接口提供，受限时提示联系管理员。

BOM 选料树和选料下拉遵循物料档案的默认分类类型参数，同时叠加人员分类权限；配置为空时显示有权限的物料分类，配置无效或无权访问时提示管理员核对，不能回退展示其他分类。

选料弹窗按当前子款与颜色尺码判断已添加物料，包括当前规格继承的有效用料；已添加项置灰且不可重复勾选，移除后重新可选。不同颜色尺码及不同子款各自判断。

BOM 主界面通过产品分类和款式树筛选版本；选中款式后新增 BOM 自动带入该款。制单页面在单据头选择款式，弹窗支持按分类树和关键词查找启用款式。新单切换款式前提示清除已填写用料，已有版本保持所属款式不变；款式范围遵循默认分类参数和人员分类权限。

列表支持按款式分类及其下级筛选，与左侧树选择取交集；显示创建人、创建时间和修改时间，修改人可在列设置中打开。列表复用公共表格的满高、分页、列设置及列宽调整能力。

BOM 版本使用全局唯一单号，默认建议格式为 BOM＋制单日期（北京时间）＋至少四位流水号，允许手工修改；建议值未修改时保存会在事务锁内重新分配，手工编号不区分大小写检查重复。复制版本取得新建议单号，历史记录使用 BOM-HIST-主键补号。单号可在列表查询，版本号仍按款式递增。
