# 物料档案

> 状态：一期已验收（2026-11-08）；权限、审计、API/Skill/MCP 资料已接入，物料 DDL 已合并主建表。后续可继续扩充各规格模板字段，按模板目录与稳定字段键演进。
> 依赖：仓库管理、仓库布局、计量单位、分类管理、颜色管理；分类授权按人员分类范围契约执行。
> 规格模板设计与字段范围见[服装物料分类与规格模板规划](../规划/专项功能/服装物料分类与规格模板规划.md)。

## 一、功能边界

物料档案是库存、采购、款式 BOM、领料及退料共用的稳定物料主数据。一个物料档案可关联多个颜色；实际收货颜色、供应商色号、缸号、来料批次、客户归属、库存数量、质量状态和库位均属于后续批次/单据，不在主档重复保存。

本期不建立供应商物料号、采购价、库存数量、最小/最大库存、默认仓库、客户专属物料绑定、条码标签、BOM、收货或领退料。物料专属包装换算已纳入本期单位配置。库存数量由后续业务按所选库存基本单位处理，箱、卷等包装不假定为全局换算。

## 二、档案字段

| 字段 | 要求与用途 |
|---|---|
| 物料编码 | 唯一稳定业务编码；自动生成规则可配置，生成建议可编辑；创建后不可改 |
| 物料名称 | 必填、便于各业务搜索的通用名称 |
| 分类类型、所属分类 | 必须引用公共分类类型和节点；按人员分类权限在服务端过滤、保存时再校验 |
| 克重、幅宽 | 可选，分别使用 g/m² 与 cm |
| 成分 | 可选，记录材质组成及比例 |
| 规格尺寸 | 可选，填写尺寸、号型或包装规格，原有综合规格文字保留 |
| 型号 | 可选型号/款式标识，未提供时为空 |
| 品牌 | 可选品牌 |
| 材质说明 | 可选补充材质与关键属性 |
| 库存单位 | 必选启用的库存基本单位；不能选择辅助单位作为记账单位 |
| 采购/辅助单位 | 物料可独立选择单位并设置用途与换算；公共换算只作为初始建议，物料系数不回写全局单位档案 |
| 可用颜色 | 通过公共弹窗按名称、编码、色值搜索和多选；停用颜色可回显已有引用 |
| 状态 | 列内启停；停用档案保留历史引用，禁止新业务选用 |
| 排序、备注 | 管理维护字段 |

分类类型默认留空时物料分类筛选展示当前人员全部授权范围；业务参数设置默认类型只负责页面初次定位，仍允许切换其他有权类型。人员范围为空须展示权限受限说明，不得伪装成无数据。类型/节点变更不能绕过服务端分类授权。

## 三、操作与界面

- 库存模块新增“物料档案”入口，页面遵循当前 `SystemTemplate.vue`、`StandardListLayout.vue`、`FoundationTable.vue` 模板；表格列宽自适应，状态列直接启停，删除单独展示在操作列。
- 可按编码、名称、规格、型号、品牌、分类类型、分类节点和状态筛选；无权限节点与资料不返回给客户端。
- 新增、编辑、物料编码导入导出、单条删除、连续“保存并新增”；正常新增空白，只有保存并新增使用上次成功表单默认值。
- 编码输入始终可编辑。服务端事务锁内只在编码为空或仍等于页面给出的自动建议时重新分配；用户编辑过的值保留并做唯一性检查。
- 导入逐行复用服务端校验与审计，失败行可查看后重试；导出只包含当前人员有权查看且当前筛选命中的档案。

## 四、权限、数据与审计

- 权限码：`inventory:material:list/add/edit/remove`。角色树挂在库存/物料档案节点下，增量 SQL 只补已有权限的祖先，不扩大任何现有角色写权限。
- 列表、选项、分类树、详情/快照、新增修改、删除及 MCP 均执行人员分类范围；无权访问与不存在不得产生可区分的信息泄露。
- 物料分类、库存单位与颜色使用稳定ID外键；所有 bigint ID 以字符串传输。
- 每次新增、实际字段修改、状态变化和删除记录业务对象名称与字段前后值；颜色集合的变更也进入审计。
- 有业务外键引用时拒绝物理删除并提示停用；无引用时可删除并保留审计记录。

## 五、数据库

- DDL 已并入唯一权威入口：`sql/主建表.sql`，包含物料主档、颜色关联、物料专属单位、规格模板目录、菜单权限及应用数据库授权。
- 表：`inv_material`、`inv_material_color`；主档编码大小写不敏感唯一，颜色关联 `(material_id,color_id)` 唯一。
- 所有表/列/索引/序列均有中文 PostgreSQL `COMMENT ON`；SQL 同时有中文业务说明。
- 按项目生命周期，用户验收后已将开发 DDL 合并至 `sql/主建表.sql`，独立增量文件已清理。后续数据库结构变更继续维护主建表；模板字段若可由 JSONB 字段目录表达，优先扩展模板字段定义与校验，不为每个规格字段单独增加物料表列。

## 七、验收清单

1. 分类类型、分类节点、库存基本单位、多个颜色能新增/编辑并准确回显；跨类型过滤和层级分类筛选正确。
2. 时间、长度等单位精度服从《计量单位API.md》契约；物料主档不做数量换算或提前舍入。
3. 编码规则开关/前缀/位数在参数设置中保存；建议可编辑，重复编码友好拒绝，并发新增不冲突。
4. 人员“全部可见/指定范围/全部不可见”覆盖列表、筛选计数、导入导出、分类选项、REST/MCP和写入；权限收回后旧页面提交失败。
5. 停用分类/单位/颜色不得新增引用；历史已引用项目在编辑回显时可见并可按规则解除，但不得新增新的停用引用。
6. 普通新增空白；连续新增仅在保存成功后记忆安全字段；关闭未保存表单提示；状态列启停和中文确认正常。
7. 导入逐行错误可定位与重试；导出不泄漏权限外类别或物料。
8. 新增、改字段、改颜色、启停、删除业务审计均有操作者、动作、对象及真实字段前后值。
9. 页面模板、功能入口、服务端菜单权限、SQL注释、API、Skill、MCP 与进度清单一致；普通角色授权和撤权验证后记录。

## 规格模板首期

- 新增和编辑弹窗可直接选择十套预置模板。通用规格尺寸可独立填写，模板与物料分类分别保存。模板字段由目录动态驱动，界面和接口不应把当前十套模板或字段写死。
- 面料 / 里布模板包含经向、纬向标准缩率（允许 -100% 至 100%，负数表示尺寸增长）、缩率测试条件和密度及口径。梭织按供应商标注经密/纬密，针织按横列/纵行密度并注明计数长度。
- 更换模板前提示会移出当前表单的字段。已保存的规格值可在切回模板时恢复，旧面料数据继续使用原字段。
- 列表支持按模板筛选，CSV 支持模板编码和规格字段对象，两版旧模板仍可导入。预置模板目录供本轮验收，模板配置页面后续独立实施。以后增加规格字段时，先确认模板适用范围、字段稳定键、类型/单位/校验和旧数据兼容，再扩展目录与表单；共用同一稳定键的字段必须保持相同业务含义，新增字段不得清除未展示的既有规格值。
- 前后端构建通过，开发库增量已执行。实际 REST 请求覆盖模板目录、通用建档、规格保存、切换及恢复、非法字段拒绝和旧面料数据兼容，临时物料已删除。用户已于 2026-11-08 完成页面验收；MCP 运行时 9 个工具已发现。

## 物料采购与辅助单位

- 库存单位每个物料一个，默认用于采购和生产领用。其他单位可多选用途，公共固定系数可带入并在物料上修改。
- 固定换算支持参照本物料其他固定单位，例如箱→盒→个；服务端拒绝循环及超出精度。实际数量模式用于每次入库数量不同的卷等包装。
- 开发增量为既有关联快照公共系数。物料专属关系不修改公共单位档案；CSV 使用单位编码记录完整配置。
- 采购、逐卷入库、卷余量、领料、历史换算快照及库存精度保护须在对应业务模块实施，本次物料档案只提供配置。
- 入库时物料的固定系数只作为默认值，允许按本次实际到货修改系数或库存数量，逐卷时可逐卷录入实际数量；单据保存实际换算及数量快照，不回写物料或公共单位默认值，数量和换算需保持一致。
- 开发库增量已执行，前后端构建通过。认证接口临时物料验证固定链式换算、实际数量模式、用途、循环拒绝、旧接口保留专属配置及公共系数不变，临时物料已删除。页面交互和导入导出仍待用户验收。

### 后续采购参考价格（2026-11-14，需求已确认、待实施）

- 物料档案增加参考采购价，支持库存单位及多个采购单位；可按供应商、物料规格、颜色等维护适用价格，明确生效时间及匹配优先级。固定换算可建议单位价格，但自动生成值可编辑；实际数量模式依据实际收货数量计算，不能预设每卷固定米数。物料专属换算不改变公共单位档案。
- 参考价用于采购单建议带出，不是库存成本；采购单及入库单可按业务和权限修改实际单价、金额和换算，保留单据历史快照。价格与供应商信息须按采购/财务权限在页面、接口及导出等路径控制，不能仅凭物料查看权限获取。
- 具体字段、价格匹配、计价方法、批次开关、客供自采及验收场景以[采购价格、入库计价与库存成本](../规划/模块/模块-财务与采购.md)为准；本条为新增规划，不改变一期、二期已验收的实现状态。
