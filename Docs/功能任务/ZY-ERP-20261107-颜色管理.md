# 功能任务：颜色管理

> 功能键：`color`
> 状态：用户验收通过（2026-11-07），交付收尾完成
> 入口：系统管理 → 颜色管理
> 前置依据：颜色基础资料全局复用；物料可多选颜色，采购/BOM按行选具体颜色，库存批次保留实际颜色、缸号和供应批次。

## 一、目标与边界

维护供物料、款式等业务共享的颜色基础资料。颜色是可复用的有名档案，通过稳定 `color_id` 引用。颜色管理仅维护系统颜色名称与可选屏幕色样，不维护某物料可用颜色集合、供应商色号、缸号、色差结果、实物色卡、收货批次或库存数量。未来物料档案通过关联明细支持一物料多颜色；不为每种颜色复制物料的全部基础信息。

色值只用于屏幕辅助辨认，不承诺显示器与实物颜色一致，不能代替实物确认和供应商色号。没有项目统一色值时允许为空。

## 二、字段与约束

| 字段 | 规则 |
|---|---|
| 颜色编码 | 必填，最多40字符，全局忽略大小写唯一；默认按 `CLR` 前缀及序号建议，规则位于参数设置，新增建议可编辑；正式保存对未修改建议在事务锁内重新分配。编码创建后固定 |
| 颜色名称 | 必填，最多80字符，去首尾空格，忽略大小写全局唯一 |
| 屏幕色样 | 可选；空或 `#RRGGBB`，服务端大写归一化 |
| 排序 | 0–999999，数字越小越靠前 |
| 状态 | `0`启用、`1`停用；状态列直接启停，停用后不允许新业务引用，但保留历史显示 |
| 备注 | 可选，最多500字符；不在这里混入供应商色号、缸号和业务批次 |

表 `base_color` 不设软删除字段。未被外键引用时可物理删除；存在任何业务外键引用时拒绝删除并提示停用。颜色名称、色值、排序可修改，所有变更写业务审计。

## 三、页面

- 列表遵循 `StandardListLayout` 与 `FoundationTable`：搜索编码/名称/色值、状态筛选、查询/重置、自动列宽、用户列设置、状态列开关、编辑/删除操作列。
- 表格以小色块和 HEX 文本展示色样；空色值明确展示“未设置色值”。
- 新增/编辑表单包含编码、名称、色样、排序、备注；原生颜色选择器配合 HEX 输入，色样可留空。颜色名称和屏幕色值需明确提示不能替代实物色卡。
- 新增时取服务端可编辑编码建议。普通新增打开空表单；仅“保存并新增”时带入上一次成功内容，移除主键和编码并重新获取编码建议。
- 支持 CSV 导入/导出；导入逐行走真实新增接口，编码/名称冲突逐行反馈，成功记录不得重复提交；模板字段为颜色编码、颜色名称、色值、排序、备注。
- 启停确认使用中文；删除提示说明有引用时不可删、可停用；启停、增删改均须记录操作者、对象、动作和字段前后值。

## 四、权限与接口

功能页面权限 `system:color:list`；新增 `system:color:add`；修改与启停 `system:color:edit`；删除 `system:color:remove`。编码规则修改复用 `system:config:edit`。所有后端写入口独立执行权限校验。菜单通过 SQL 挂至系统管理，路由也执行页面访问检查。

REST/MCP 契约见[颜色管理 API](../API/颜色管理API.md)。业务选项接口返回停用项目供历史显示并带 `selectable`，仅启用项可新增引用。

## 五、验收清单

- 新增/编辑/启停/删除及重复编码、重复名称、非法色值、边界长度均有服务端校验。
- 自动编码可在参数设置启停、改前缀和位数；新增建议可手工改；关闭自动生成后必须手输；并发未修改建议不会撞码。
- 颜色名称与 HEX 色样在列表、编辑和选项 API 一致；无色值状态明确。
- 启停位于状态列，停用项仍可读历史但不能新选；删除由所有已声明外键保护。
- CSV 模板导入导出可用；导入混合成功/失败行可识别并下载失败行。
- 用户权限不同的菜单、按钮和 API 访问一致；未经授权的直接 REST 请求被拒。
- 系统日志能追溯新增、编辑、启停、删除和编码规则修改的对象、操作者、动作、时间及字段前后值。
- 颜色代码、表字段和 API 均有中文业务说明；DDL 已合并主建表，迁移可重复执行。
