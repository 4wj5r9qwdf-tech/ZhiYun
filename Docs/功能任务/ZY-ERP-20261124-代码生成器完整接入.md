## 一、业务目标与范围

- 解决的问题：后端已有 ruoyi-gen 代码生成器，但 ERP 页面缺少部分表级配置、字段配置、批量操作，扩展选项也未按后端契约持久化。
- 目标用户/角色：拥有 tool:gen 对应权限的系统维护人员。
- 本次包含：数据源和候选表查询、表结构导入、配置列表筛选、表级配置、字段配置、单表 CRUD/树表模板、Vue/React 前端模板、生成菜单父级、预览、单表与批量下载、数据库结构同步、单条与批量删除生成器配置。
- 本次不包含：上游独立拖拽式在线表单/页面构建器；把源码自动写入 ERP 仓库、自动执行生成 SQL 或自动发布页面；改变 ruoyi-gen 后端规则或新增业务生成模板。
- 前置条件与依赖：RuoYi-Vue-Plus ruoyi-gen 模块及其 /tool/gen 接口；登录人员具有相应 tool:gen 权限。父菜单树另需 system:menu:query；未授权时仍可输入数字菜单 ID。
- 已确认规则：代码生成只产出 ZIP，不自动进入正式业务菜单或上线；同步只更新生成器保存的列元数据；删除只清理生成器配置和字段配置，不删除业务表。
- 待决定事项：无；实现后由 JY 验收页面体验。

## 三、业务契约

- 输入与操作：选择数据源及一个或多个表导入；编辑表描述、实体名、包路径、模块/业务/功能名、作者、CRUD/树表、Vue/React、父菜单、导出/状态/唯一/排序以及列属性；预览或下载单张/多张生成结果。
- 输出与状态变化：导入创建 gen_table 与 gen_table_column 配置；保存更新生成器配置；预览返回文件内容；下载返回 ZIP；同步刷新已导入表的字段元数据；删除清理生成器自身记录。
- 异常、边界和重复操作：后端继续执行字段存在性、必填项、重复提交及权限校验；页面先检查必填项、树表字段和数字菜单 ID。候选表由后端排除该数据源已导入表。同步会新增数据库新列、移除数据库已删除列，部分控件选项可能按框架默认规则更新。
- 权限与数据范围：列表、数据源、候选表使用 tool:gen:list；详情使用 tool:gen:query；导入使用 tool:gen:import；保存/同步使用 tool:gen:edit；删除使用 tool:gen:remove；预览使用 tool:gen:preview；单表/批量下载使用 tool:gen:code。前端显隐不替代后端 Sa-Token 检查。
- 删除策略：删除生成器配置不删除数据库表和业务数据；需要继续生成时重新导入。同步仅维护生成器元数据，不修改数据库物理结构。
- 关联数据来源：表配置读取选定数据源的数据库元数据；生成 SQL 含目标菜单记录，执行前需检查数据库、菜单 ID 和权限码。
- 下游影响：不会执行 SQL、改写 ERP 页面或业务数据。下载者需审查源码并按项目规范集成、测试及部署。

### API 与权限

| 方法/路径 | 用途 | 请求/响应与副作用 | 权限 |
|---|---|---|---|
| GET /tool/gen/list | 查询已导入配置 | 表名、说明、数据源和分页过滤 | tool:gen:list |
| GET /tool/gen/getDataNames | 查询数据源列表 | 返回可用数据源名称 | tool:gen:list |
| GET /tool/gen/db/list | 查询候选数据库表 | 依数据源分页；过滤已导入表 | tool:gen:list |
| GET /tool/gen/{tableId} | 查询表和字段配置 | info 与 rows 一次返回 | tool:gen:query |
| GET /tool/gen/column/{tableId} | 独立查询字段 | 配置页由详情接口提供字段，不重复请求 | tool:gen:list |
| POST /tool/gen/importTable | 导入表结构 | tables 为逗号分隔表名，dataName 为数据源 | tool:gen:import |
| PUT /tool/gen | 保存配置 | 表级扩展值放入 params，框架序列化至 options | tool:gen:edit |
| GET /tool/gen/preview/{tableId} | 预览代码 | 返回文件路径及生成文本映射 | tool:gen:preview |
| GET /tool/gen/download/{tableId} | 下载单表结果 | ZIP 文件流 | tool:gen:code |
| GET /tool/gen/batchGenCode | 批量下载 | tableIdStr 是逗号分隔表 ID；ZIP 文件流 | tool:gen:code |
| GET /tool/gen/synchDb/{tableId} | 同步列元数据 | 更新生成器字段配置，不改真实业务表 | tool:gen:edit |
| DELETE /tool/gen/{tableIds} | 删除一个或多个生成器配置 | tableIds 是逗号分隔路径参数 | tool:gen:remove |
| GET /system/menu/treeselect | 选择生成菜单父级 | 可选依赖；无权限时可手输数字 ID | system:menu:query |
