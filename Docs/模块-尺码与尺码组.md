# 尺码与尺码组

入口：系统 → 尺码管理、尺码组管理。负责人：Codex。状态：一期实现，待用户页面验收。

## 档案与规则
- 尺码（Size）：名称必填，英文名称、类型标签、排序、备注可选；系统生成稳定编号，启停保留引用。
- 尺码组（Size Group）：名称必填，编号自动生成，类型标签、排序、备注可选；至少一个尺码，明细有独立顺序，同组禁止重复ID或同名尺码。
- 不内置尺码、尺码组和类型标签。标签归属首次使用时按通用标签机制登记。
- 停用尺码不能新加入组，已在原组中的停用尺码允许保留、移除及调整顺序。未保存的新组不得引用停用尺码。
- 不提供物理删除。数据库外键保护主从关联。
- 后续样衣选择尺码组，再确定实际样衣尺码；业务保存尺码名称、顺序快照。样衣与快照逻辑留待样衣模块实现。

## 接口与权限
- /system/size-data/size、/system/size-data/size-group：POST新增，PUT /{id}编辑，PUT /{id}/status启停，GET /list管理查询，GET /options登录业务选择。
- system:size:list/add/edit、system:size-group:list/add/edit。角色管理从 sys_menu 读取这些权限；普通角色需要管理员授权。
- PostgreSQL：sys_size、sys_size_group、sys_size_group_item；表及字段均有注释，主从保存使用事务，组内ID及排序有唯一约束。
- 新部署执行主建表脚本，旧环境执行 sql/尺码与尺码组_20261103.sql。

## 验收
新增尺码和标签、编辑排序；建立尺码组并调整顺序；重复尺码拦截；停用后旧组保留、新组不能选用；普通角色权限控制；空表铺满及列设置。页面由用户验收。
