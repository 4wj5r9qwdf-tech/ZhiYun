# 功能命名清单

> 版本：v1（首批功能已定：登录与认证）
> 更新日期：2026-10-24
> 说明：本清单是《开发规范.md》"功能命名规范"章节的落地载体。所有新功能/功能改名必须先在本清单确认命名，才允许开发对应功能；数据库表名必须与本清单的英文口径严格对应。

## 使用规则
1. 每行 = 一个功能；"状态"取值：待确认 / 已确认 / 已改名 / 已废弃。
2. "功能英文名"是数据库表名前缀、代码模块名的唯一英文口径，全系统不得各译各的。

3. "功能英文名"优先取《术语词库索引.md》/服装加工厂专业名词词库.json 既定英文；无既定词才新造并回填词库。
3. 涉及多张表的功能，主表 = 功能英文名，明细表 = 功能英文名+`_item`/`_detail`，日志表 = 功能英文名+`_log`（业务域前缀另加，如 `base_`/`prod_`/`inv_`）。
5. 改名/废弃不删除原行，改"状态"列 + 备注说明改成了什么。
