# 功能命名清单

> 版本：v1.1（统一功能命名登记）
> 更新日期：2026-11-05
> 说明：本清单是功能名称与英文/表名口径的统一登记表，不是开工审批表。负责人依据用户用语、现有功能边界和词库自主确定常规命名并登记；实质改变业务边界或影响外部契约时再提交用户决策。

## 使用规则
1. 每行 = 一个功能；"状态"沿用表内的待确认 / 已确认 / 已改名 / 已废弃。待确认表示该条目的命名或业务范围尚有待决事项，不自动阻塞无关且已获授权的工作。
2. "功能英文名"是数据库表名前缀、代码模块名的唯一英文口径，全系统不得各译各的。

4. "功能英文名"优先取《术语词库索引.md》/服装加工厂专业名词词库.json 既定英文；无既定词才新造并回填词库。
5. 涉及多张表的功能，主表 = 功能英文名，明细表 = 功能英文名+`_item`/`_detail`，日志表 = 功能英文名+`_log`（业务域前缀另加，如 `base_`/`prod_`/`inv_`）。
6. 改名/废弃不删除原行，改"状态"列 + 备注说明改成了什么。

- 术语：客户档案 / Customer Master；功能键 `customer_master`。

### 国家/地区基础资料（2026-11-03）

- 术语：国家/地区 / Country / Region；国家/地区编码 / Country / Region Code。
- 入口：系统 → 国家/地区；功能键 `system_country_region`，页面 `CountryRegionManage`。
- 接口 `/system/country-region`；维护权限 `system:country:list/add/edit`；业务选择接口只要求登录。
- 表 `sys_country_region`；稳定编码可被客户所在地区、客户地址及未来订单/发货目的地分别引用。
