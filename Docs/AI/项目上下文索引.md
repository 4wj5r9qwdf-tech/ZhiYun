# 项目上下文索引

## 项目简介

织云 ERP 面向服装加工企业，覆盖款式、订单、生产及经营支撑业务。系统技术栈、业务规划、模块边界和当前完成状态分别见下列权威资料；本索引只负责导航，不复制细则。

## Agent 首次入项

1. 阅读仓库根目录 [`AGENTS.md`](../../AGENTS.md)。
2. 根据任务类型读取本页相应的正式文档。只读取完成当前任务所需的内容，并在实施前核对代码和动态状态。
3. Codex 内置长期记忆只作检索摘要；项目规则的唯一有效来源仍是本页列出的正式文档，不能用记忆替代规范。
4. 稳定架构、业务规则或长期协作约定变化时，更新对应的权威文档；临时状态更新到功能状态或任务记录。

## 事实与冲突处理

- 当前用户明确确认的业务决定、相应专项需求文档、工程规范和智能体本地记忆属于不同层次，不能互相替代；本页定义每类内容的归属。
- 代码和数据库能证明当前实现了什么，不能单独证明业务规划或权限设计已经获批。
- 两份正式资料对同一规则给出不同要求时，先记录冲突文件和条款。若会改变业务结果、数据含义、权限、安全或生产操作，提交有影响说明的决策项；其他情况采用最小风险且可回退的处理，并推动更新唯一权威来源。
