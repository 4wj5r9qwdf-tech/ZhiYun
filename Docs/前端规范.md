## A、公司切换（定稿）

### A.1 双公司、可切换
- 厂里有两个公司实体，各一套**名称 + logo**。
- **两个公司名称都由管理端自己编辑**（不写死在代码里），各配一个 logo 文件。
- 建一张"公司档案"：`公司ID / 公司名(可编辑) / logo(文件) / 是否启用 / (A.5 主题)`，**两个**条目，可增（后期加第三公司不用改表）。
- 这张表既是"展示公司"来源，也是"业务归属公司"来源（每张单据的归属公司 = 选这张表里的一项）。

## A.0 两层要分清（核心，别混）
**公司名/logo 出现在系统里有两层，跟的东西不一样：**
| 层 | 跟随 | 何时定 | 验厂切换时 |
|---|---|---|---|
| **展示层**（登录页/首页/页头/内部页露出的公司名logo） | **当前展示公司（全局切换）** | 随时切 | **变**（纯视觉） |
| **业务层**（订单/报销/采购单/打印单 的抬头、开票主体、走哪个公司账） | **单据自身的"归属公司"字段** | **开单时定、之后锁定** | **不变**（业务事实，不随展示切） |
→ **打印/报表抬头 = 该单据"归属公司"，不是"当前展示公司"。**（验厂切成 B 展示，归属 A 的采购单打印抬头仍是 A。）

### A.2 切换触发场景与入口（你定的）
- 平时用一个默认公司名；**领导检查、客户验厂**等特定场景，切换显示另一家公司名/logo。
- 切换入口：**放在"系统管理"模块里**（"系统"一级图标 → 右侧"公司档案/切换公司"功能卡片），切换后全站即时生效，不重启。**不放在顶栏**（顶栏只留公司名展示，不放切换控件，避免顶栏挤占 + 误操作）。
- **谁能切公司 = 走角色权限控制（不写死"只超管"）**：公司切换作为一个操作项挂进 地基/权限与组织树 的权限模型，哪个角色/哪个人能切，**按角色权限配**；默认给超管，管理员可加给"厂长"等任意角色（验厂场景）。**不硬编码"只超管"，不写死名单。**

### A.3 切换作用范围（仅限"展示层"）
"当前展示公司"切换时，**只影响这些纯展示位置**（登录页/首页/各页页头的公司名+logo）：
- **登录页**：公司名 + logo
- **首页**：公司名 + logo
- **各功能页/内部展示**：页头/标题露出的公司名
> **注意：单据/报表的抬头公司名"不属于展示层"，它属于业务层，跟随单据"归属公司"（A.0），不随此切换变。**

### A.4 实现原则（不重复造轮子 + 不写死）
- 公司名/logo **全走"当前展示公司"这个配置项**（后端一个 `当前公司ID`，前端读它渲染），**禁止在任何页面/模板/报表里硬编码公司名或 logo 路径**。
- 报表/打印的抬头公司名+logo，统一从一个"报表抬头组件/模板"取（跟 15.18 装箱分拣单打印模板那套共用），一处改全站跟。
- 公司档案的字段注释、命名走《开发规范》/《术语词库索引》。
- 审计：谁在什么时候切了公司，留痕（防"验厂时切了忘切回来"）。

### A.5 多主题（每家公司可配一套视觉主题）
- 公司档案除"公司名/logo"外，**再挂一套视觉主题**（主色/深浅等，字段可配）；**切换公司 = 切公司名/logo + 切该公司主题**，一套机制两件事（不另起炉灶）。
- 系统提供**多个可选主题**（如 默认工业蓝、深色大屏、各公司自定义色），管理端可**为每家公司单独设**或**统一用同一主题**，均可。
- 主色/主题**只影响配色皮肤**，不影响布局/交互铁律（B.3 车间卡片化不因换主题变）。

### B.1.1 品牌色与主题（A.5 落地值）
- 默认主题 = 工业蓝 `#1E5EFF`（主色）+ 中性灰阶；深色主题底 `#0E1526`、高亮跟主色走。
- 每个公司档案可挂一套主题（主色/深浅），**切换公司=切公司名/logo+切该公司主题**（A.5 原机制）；主色只换皮肤，不动 B.3 车间卡片铁律。
- 预警/看板"红黄绿"固定：绿 `#00B388`、黄 `#FF9500`、红 `#F53F3F`，全系统统一，不随主题变。

### B.2 密度按角色分（同一套系统、不同密度）
- **车间工人**：大字（正文 ≥18px、按钮 ≥48px 高）、单屏少元素、防误触（扫一下干一件事）
- **组长/主管**：中等密度，看自己组的数据
- **文员/领导**：高密度，表格/看板/报表（表格行高紧凑、多列并排）
- 密度档由"当前用户角色"自动带出（角色→密度档映射走配置），不靠页面各写各的；车间工人端即使有管理功能入口，也保持大字号。

### B.5 视觉落地验收（写代码时对得上号）
- 每个新页面提测前自查：主色/预警色用没用 B.1.1 的值（不各取色）？车间端有没有违规下拉（B.3）？密度档对不对角色（B.2）？公司名/logo 走没走"当前展示公司"配置（A.3，没硬编码）？
- 截图存档进《开发日志》对应周次，跨端（PC/小程序/大屏）同一功能视觉一致。

### B.5.1 数据表格交互 + 全局搜索 + 卡片布局自定义（强制，全站共用一套组件，不自造）

**全局搜索（顶栏红框位：公司名右侧，常驻控件，Ctrl+K 随时唤起）**

**功能卡片布局自定义（右侧功能网格，按"模块+用户"记忆，不写死）**

- **置顶/顺序/大小/工作台 都是"该模块+该用户"维度**（存 sys_user_menu_config），不影响他人、不写死。

### B.5.1.1 列表页标准布局（一阶段定版，2026-10-25，以 `views/Person.vue` 为唯一基准）

**铁律：所有列表页（一阶段）必须 100% 照此标准实现，禁止自行发挥。** 新建列表页**直接复制模板 `frontend/src/views/_template/ListTemplate.vue`**（A~E 全量骨架：标题行/筛选栏/列设置/列宽拖拽/批量占位/标准样式/弹窗，全带 TODO 注释，搜索 TODO 逐处替换即可），不要从 Person.vue 抠结构、更不要等用户挑毛病再改。复制出 `_template` 目录后记得 `../../api` → `../api`。基准文件：`frontend/src/views/Person.vue`。

**A. 页面骨架（自上而下，顺序固定）**
1. **标题行 `.page-header`**：`←` 返回（跳回所属模块首页，如 PersonIndex/PropertyIndex/SystemIndex）+ 标题。**操作按钮一律不放这里。**
2. **筛选栏 `.filter-bar`**（白底圆角卡片，与表格间距 12px）：
   - 左侧：搜索框 + 若干筛选下拉（层级/状态/部门/性别等，按本模块可筛字段），**查询 / 重置** 按钮。
     - **查询 = `type="primary"` 蓝底白字、无图标**（`<a-button type="primary">查询</a-button>`）；**重置 = 默认按钮、无图标**（`<a-button>重置</a-button>`）。三者（Person/Org/Group…）一律如此，禁止加 `ReloadOutlined` 等图标、禁止用普通按钮当查询。
   - 中间：`<div class="filter-spacer"></div>` 弹性隔开。
   - 右侧：**操作按钮**——【新增】（primary）+【导入】+【导出】等，放这一行靠右，**不放标题行**。
   - 无独立"刷新"按钮（查询即刷新）；无面包屑（Home 的"模块/XX"已删）。
3. **列表工具行 `.table-bar`**：左 `共 N 条`（`.total`）+ 右 **⚙ 列设置** 受控下拉（`colSetOpen`，操作期间不自动收起）。
4. **`a-table`**：撑满容器。

**B. 表格配置（四件套 + 拖拽，缺一不可）**
| 能力 | 实现（照 Person） |
|---|---|
| **序号** | 固定第一列：`{ title:'序号', key:'index', width:64, align:'center', fixed:'left' }`——**不进 colState（不可隐藏、不参与列设置顺序）、不给拖拽手柄**（`onHeaderMouseDown` 里 `key==='index'` 直接 return）；bodyCell：`(pageNum-1)*pageSize + index + 1` 页内连续编号（无分页页直接 `index+1`） |
| 排序 | 数值/日期列 `sorter: true`，`@change` 走后端 orderBy |
| 列设置（显隐+顺序） | `colState`（`{key,visible,width?}`）+ `ALL_COLUMNS`，`columns` 用 `computed` 按 colState 顺序/显隐生成，操作列固定 `fixed:'right'` 最后、不可隐藏；localStorage key = `{页名}:{userId}` |
| **列宽拖拽** | **原生表头 th（禁用 `tableComponents` 自绘——自绘不参与 colgroup 列布局，会与数据错位）**：列定义加 `customHeaderCell: () => ({ onMousedown, onClick })`；`onHeaderMouseDown` 判定 `e.clientX < rect.right - 14` 才生效，绑 document mousemove/mouseup 改 `colState.width`；mouseup 后置 `suppressHeaderClickUntil=Date.now()+300`，`onClick` 在窗口内 `preventDefault+stopPropagation` 吞掉排序 click（否则拖完触发排序重排、边框跳变）；手柄用**非 scoped** `<style>` 里 `.ant-table-thead > tr > th::after { right:-1px; width:12px; border-right:2px solid #E5E8EF; cursor:col-resize }` 画（scoped 匹配不到 `h()` 渲染元素）；**操作列/序号列不给拖拽**（mousedown 里 `key==='ops'||key==='index'` 直接 return） |
| **操作列** | **图标 + 文字 + Tooltip 防误触**：`<a class="ops-link"><EditOutlined />编辑</a>`；删除 `danger-link + DeleteOutlined`；项间距用 `.ops-link{ display:inline-flex; gap:4px; margin-right:10px }`（**不用 a-divider 竖线，裸文字链接太挤易误触**）；操作列宽 Person 150 / 其他 120~190 按项数 |
| 行样式 | `.person-table` 类：`width:100%` 白底圆角 10px、表头底色 `#FAFBFD`、行悬停 `#F5F8FF`、列间浅竖线 `#F0F2F5`（`:deep` 覆盖）、`font-size:13px` |
| 固定高度滚动 | `:scroll="{ x:'max-content', y:'calc(100vh - 360px)' }"` |

**C. 批量操作（按需，2026-10-26 定）**
- **何时加**：页面有批量诉求（批量删除/批量改状态/批量分配等）才加勾选列；没有批量诉求的页面**不强制**（如部门删除有层级校验、单条操作已够，就不加）。
- **怎么加**（照 `PostManage.vue`）：
  - `a-table` 加 `:row-selection`（`selectedRowKeys` + `onChange`），**换页时清空选择**（`onPageChange` 里 `selectedRowKeys=[]`）。
  - 批量按钮放**筛选栏靠右**（`filter-spacer` 之后、新增按钮之前）：删除类用 `danger`，**无选中时 `:disabled`**，文案带数量如 `删除选中（3）`。
  - 执行前 `Modal.confirm` 二次确认；失败时透传后端 msg 并让确认框停留（`throw`），不静默关闭。
  - 删除后当前页删光自动回退一页。

**D. 筛选行为**
- 筛选**基于当前数据集**（后端分页传参）；有筛选时合计/计数随结果集变。
- **搜索铁律（2026-10-26 岗位页踩坑）：后端分页的页面，搜索必须走后端全库匹配，严禁前端 filter"当前页"数据**——后端只把当页 N 条给前端，第 2 页起的数据本地根本没有，前端过滤必然搜不到（岗位页曾因此搜不到第 2 页的"裁剪组长"）。做法：keyword 随 loadList 传参，后端 like/OR 匹配，查询回第 1 页。仅"全量加载无分页"的页面（部门/小组）允许本地过滤。
- 关键词支持回车（`@press-enter`）触发查询。
- 带软删除的表：筛选栏加"查看已删除"复选框，此时操作列只给"恢复"。

### B.5.1.2 表单弹窗标准（新增/编辑，2026-10-26 定，基准 `views/Person.vue` 人员弹窗）

**铁律：字段≥15 个的业务表单一律 Tab 分页，禁止"标签上输入框下"的密集格子墙一屏硬塞。**

1. **Tab 分页**：`a-modal`（宽 **1100px**）内 `a-tabs` 按业务分组分页（如 基本信息/任职信息/合同薪酬/社保保险），每屏≤15 字段、留白清晰；**字段只有 2~3 个的小组并入相邻 Tab**（如 手机号/邮箱并入基本信息，不单开 Tab）；保存/取消在 modal footer 常驻。
   - **防横向滚动条**：`body-style` 必须带 `overflowX: 'hidden'`——`a-row :gutter` 的负边距在 overflow 滚动容器里必然溢出产生横滚条（丑且无意义），加宽 modal + hidden 裁掉即可。
2. **校验跳 Tab**：`save` 里 `validate()` catch 到 `errorFields[0].name`，按字段→Tab 映射自动 `activeKey` 切到出错页（如 `ext.hireDate`→任职信息），用户不用自己找。
3. **body 限高**：`body-style="{ maxHeight: '68vh', overflowY: 'auto' }"` 兜底内滚，footer 永不被顶出屏。
4. **多选字段**（≥10 选项）：禁用 `a-select mode="multiple"`（无模糊搜索、长列表难选），用 **"已选 tag(可删) + 选择按钮 + 勾选弹窗"**（弹窗内搜索框模糊过滤 + checkbox + 确定回填），基准 Person.vue 的岗位/角色选择器。
5. 开弹窗时 `activeKey` 重置到第一页。
6. **弹窗关闭约定（防误触丢表单）**：所有业务 `a-modal` 一律 `:mask-closable="false"` + `:keyboard="false"`——**点遮罩/按 ESC 都不关闭**，退出只走【保存/取消/右上角 X】。注意 Vue 裸写 `mask-closable` = true（等于没关），必须显式 `"false"`。全站 8 处弹窗已统一（人员×2/岗位/小组/部门/建筑/公司/模板）。

### B.5.2 数据表格交互（所有列表页共用一套组件）
列表页表格统一用**同一个表格组件**（踩"不重复造轮子"），行为定死：

**筛选条件做全**：每个列表页把该模块可筛字段都做成筛选项（支持常用 + 全量），筛选项按角色/模块过滤（无权限的字段不出现）。

**列级交互（四件事都要有）**：
| 能力 | 规则 |
|---|---|
| 排序 | 数值/日期列可点击列头升降序；**排序基于当前筛选后的数据集**（不是全表） |
| 列筛选 | 表头内联筛选（输入框/枚举下拉/多选），筛选后行集更新 |
| 列显隐 | 表头"设置列"弹层，可勾选显示/隐藏列；**隐藏的是视图，数据还在** |
| 列顺序 | 表头可拖拽调换列顺序；**用户偏好按"该列表页+该用户"记住**（localStorage/用户偏好表，不写死） |

**合计行（重点）**：
- 表格**底部固定一行合计**，只对"数值类列"求和（金额/数量/米数等，按列类型判定）。
- **合计 = 当前筛选+排序后的行集重算**，不是全表合计；用户加了筛选条件、列筛选、或翻页（若合计是"全部结果集"口径则全量重算，"当页"口径则当页），合计行随数据集变。
- 合计行样式与数据行区分（浅底、加粗、贴底固定不随滚动消失）。
- 合计口径（当页 / 全部结果集 / 全表）= 每个列表页的配置项，不写死；默认"全部结果集"。

**实现**：列显隐/顺序/筛选/排序/合计 全部封装进这一个表格组件（前端组件库的 Table 扩展 + 合计 row），**禁止每个页面各写一套表格行为**（同 B.4 强制）。

### B.5.3 UI 组件库（ant-design-vue 4.2.6）——当前全站统一用它

**是什么**：`ant-design-vue@4.2.6`（企业级 Vue3 组件库，antd 生态），全站 UI 基础。除功能卡片 `FunctionCardGrid` 这类深度定制组件保留自绘外，**表格/表单/弹窗/控件/反馈一律用 antd，禁止手写**。图标用 `@ant-design/icons-vue`（已装为直接依赖）。

**怎么引入（配置已就绪，无需再动）**：
- `vite.config.ts`：`unplugin-vue-components` + `AntDesignVueResolver({ cjs:true, importStyle:false })` —— `cjs:true` 规避 Vite 8 严格 ESM 目录导入问题；4.x 走 CSS-in-JS 无需 importStyle。**已实测 Vite 8.3.5 + TS 6 dev/build 双通过**。
- `App.vue`：`<a-config-provider :theme="themeConfig">` 统一主题，`themeConfig` 在 script 里定义（**别在模板内联对象里写注释/复杂表达式，Vite prod 编译器会报 Unexpected token**）。
- `tsconfig.app.json`：`skipLibCheck` + `types: ant-design-vue/typings/global`。

**主题定制（只改 Token，不覆盖组件样式）**：
```ts
// App.vue
import theme from 'ant-design-vue/es/theme'   // 注意是 default 导出
const themeConfig = {
  token: { colorPrimary:'#1E5EFF', colorInfo:'#1E5EFF', borderRadius:8, controlHeight:36, colorBgLayout:'#F5F7FA' },
  algorithm: [theme.defaultAlgorithm, theme.compactAlgorithm],  // 紧凑算法，界面更轻
}
```

**怎么用（写页面时）**：
- **组件**：直接写 `<a-xxx>`（kebab），`unplugin-vue-components` 自动按需引入，无需 import。如 `a-table`/`a-form`/`a-modal`/`a-input`/`a-select`/`a-button`/`a-card`/`a-badge`/`a-list`/`a-empty`/`a-spin`/`a-alert`/`a-dropdown`/`a-auto-complete`/`a-avatar`/`a-tag`/`a-typography-title` 等。**子组件用 kebab**（`a-input-password` 而非 `a-input.Password`，后者 TS 报错）。
- **图标**：`import { XxxOutlined } from '@ant-design/icons-vue'` 具名引入；或动态渲染字符串名（见 config/modules.ts + Home.vue 的 `Icon(name)` + `<component :is>`）。
- **反馈**：`import message from 'ant-design-vue/es/message'`（**default 导出**，不是命名）；`import Modal from 'ant-design-vue/es/modal'`，用 `Modal.confirm`。**顶层 barrel `from 'ant-design-vue'` 会把全库打进主包，必须走 es 子路径**。
- **Vue 惯用写法**：`v-model:value` / `v-model:open` / 具名插槽 `#overlay`/`#option`；**禁止 React 风格**（`:content`/`:visible`/JSX props）。
- **模板内联表达式**：别在模板 `:绑定` 里写带 TS 类型标注的箭头函数（`(e: any) => ...`）或对象字面量内注释——Vite prod 编译器报 `Unexpected token`；抽成 script 里的方法/常量再绑。

**参考实现（新模块照抄）**：
- 列表页（表格+筛选+表单弹窗+校验+导入导出+反馈）→ `views/Person.vue`
- 卡片列表页（a-card 网格+上传+确认删除）→ `views/Company.vue`
- 登录页（a-form+a-alert）→ `views/Login.vue`
- 顶栏（a-auto-complete 搜索+a-badge 铃铛+a-dropdown 用户菜单）→ `components/TopBar.vue`
- 布局壳侧栏（antd 图标动态渲染+待办红点）→ `views/Home.vue` / `views/Workbench.vue`

**目录配置（系统级，集中维护）**：`src/config/modules.ts` —— `MODULES`（13 模块导航）、`MODULE_FUNCTIONS`（功能卡片目录，icon 用 antd 图标名字符串）、`functionsOf(moduleKey)`、`functionMap()`。新模块/新功能加到这，别在各页面硬编码。

**遗留优化**：`cjs:true` 使 antd 全量 lib 进主包（~3.4MB/gzip 766KB）；message/Modal 已走 es 子路径剥离成独立 chunk。上线前可进一步优化（改 `cjs:false`+调 ESM 解析，或 `externalizeDepsPlugin`）。

**PC 后台"双层"布局（替代侧边栏长文本菜单）**：

### B.3 车间端交互铁律（强制，覆盖默认）
车间端（平板/小程序/App）的**选择类交互一律卡片化，不用下拉列表**：
- **选工序 / 选人员 / 选料种 / 选动作 / 选库位** 等，一律用 **卡片/大按钮**（一屏几个、点开即选、点完即干），**禁止下拉框**（一长串小字车间没法用）。
- 原因：操作工多为中老年、强光、戴手套，下拉小字看不清/点不准；卡片大按钮一戳一个。
- 卡片卡片上写**大字号标签 + 图标**，高频项置顶/可"常用"置顶（同旧项目"功能入口收藏"思路）。
- 长列表（如几百人）用**搜索/常用置顶 + 卡片**，不滚一长串。
- 这条是**硬约束**：任何车间端页面出现"选 X"，先查本条，默认卡片，不用下拉。

### B.4 强制
- 全站统一走本规范 + 组件库，**任何新页面不得自造视觉/另起一套样式**（否则几百页面会乱）。

## 全局原则（呼应《开发规范》"能配置就不写死"）
- 凡是**能通过 角色权限 / 自填属性 / 功能开关 表达的，一律不写死**在代码里：
  - 公司切换谁能切 → 角色权限（A.2）
  - 公司名/logo/主题 → 公司档案自填（A.1/A.5）
  - 车间卡片化、密度、各模块强控点 → 功能开关/配置（B.2/B.3 及 各模块）
- 写进代码的只有"机制"，"值"全走 权限/属性/开关。
