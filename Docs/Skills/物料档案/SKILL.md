# 物料档案 Skill

## 适用场景

用户要求查询、筛选、新增、修改、启停或删除物料档案时使用。物料档案是库存、采购、BOM、领料与退料共用的主数据入口，不用于维护库存交易。

## 调用前

1. 确认当前连接使用发起员工本人的登录身份，禁止借用管理员或超管 token。
2. 查询 `material_category_options`，只使用工具返回的当前人员可访问且可选分类。祖先路径节点 `selectable=false` 仅用于定位，不得选作物料分类。
3. 新增或修改时查询单位和颜色公共选项。库存单位必须为启用的独立基本单位。辅助单位只提交本物料需要且直接换算到库存单位的单位 ID。停用单位、颜色只能用于已有资料的历史回显，不能建立新引用。
4. 所有 bigint 主键以十进制字符串传输，不转换为浮点数或不安全的 JS number。

## 查询

- 使用 `material_list` 查询管理档案；可按名称/编码/规格/型号/品牌、分类类型/节点或状态筛选。
- 用于新业务选物料时调用 `material_options`，只选择启用物料。
- 不能因结果为空断言系统没有该资料；人员分类范围可能过滤了结果。向用户说明可联系管理员核对分类授权，不泄露范围外类型、物料名称或是否存在。

## 写入

- 创建前先展示编码、名称、分类类型和节点、规格、型号、品牌、材质说明、库存单位、所有颜色、排序和备注，并取得用户确认。
- `code` 可由 `material_next_code` 取得，但必须让用户可编辑；不能把自动编码当作固定值。不要省略用户指定的编码。
- 修改前读取当前档案并展示拟修改字段差异；`material_update` 要传完整最终颜色集合，空数组表示清除全部可用颜色关联。
- 启停前告知结果：停用阻止新业务选择，但不删除历史引用；执行 `material_set_status` 需确认。
- 删除前展示编码和名称并确认；被业务外键引用时后端会拒绝，改用停用。删除不能作为清理历史引用的办法。
- 导入或批量场景应逐行调用/处理，逐项汇报成功与失败；不得将未授权分类映射到“最接近”的其他分类。

## 业务边界

- 物料档案的颜色是可用颜色集合。供应商色号、染缸号、实际到货颜色、质量检验、来源客户、批次、数量及库位需由库存收货/批次功能记录。
- `inventoryUnitId` 必须是基本库存单位；物料数量、采购数量和换算精度需遵循《计量单位API.md》，使用十进制定点计算，不得自行固定两位小数或提前舍入。
- 箱、卷、包等包装比例可能因物料不同，不得推导为通用单位关系。
- 分类是资料归属，标签是可扩展属性；不得从名称、编码前缀或标签推断分类授权。

工具契约见[物料档案 API](../../API/物料档案API.md)。物料档案一期于 2026-11-08 验收通过；该日运行时已发现 9 个 MCP 工具。工具是否可调用及写入权限仍应按当前运行环境核实，不以发现结果代替写调用验证。


填写规格模板前调用 `material_spec_templates` 查询当下模板和字段定义，向用户展示模板及规格值后提交 `specTemplateCode` 和 `specValues`。模板由用户直接选择，不得依赖或硬编码模板数量或模板目录。更新时省略模板字段可以保留已有选择。数字规格使用十进制字符串，是否字段使用布尔值。项目可在后续迭代为不同模板增加规格字段；调用方须按目录动态呈现并保留未展示的既有字段。新增字段使用稳定字段键，且同一键在不同模板中必须表示相同业务含义。

维护物料单位时，`materialUnits` 每行包含单位、用途及换算方式。固定换算记录参照单位和精确系数，允许箱参照盒、盒参照库存单位；实际数量方式由后续业务记录每次实际库存数量。公共换算仅作建议，物料系数不会修改计量单位档案。写入前向用户展示单位、用途和完整换算关系。库存单位无需重复添加。不要把实际数量方式推算成固定系数，业务单据须保存当时的数量和换算快照。

物料固定系数是入库单的默认值，入库时允许按实际到货修改系数或实际库存数量；单据保存该次实际换算及数量快照，不自动回写物料或公共单位。入库功能尚待开发，不将本约定描述为已有单据能力。


## 二期多规格和属性

- 先确认是否需分规格备货。需要时建立独立规格，每条有编码、名称和状态。同一物料内编码不重复，不同物料可共用编码。已有规格保留 ID，退出新业务选择时停用。
- 查询当前模板后，向用户确认哪些字段共用、哪些随规格变化。共用字段提交到 `specValues`，按规格填写的字段键提交到 `variantFields`，每条规格值放到 `variants[].attributes`。调整时同时提交 `multiSpec` 及完整规格集合。启用规格必须填齐已选的按规格属性。
- 旧自由文本尺寸已经退出页面录入。用模板属性记录尺寸，尺寸区分库存时再建立独立规格。
- BOM 先选物料档案，再在明细指定具体规格。试算按规格区分，入库和库存台账仍待对应模块接入。
