# 分类管理

> 版本：v1
> 更新日期：2026-11-05
> 说明：2026-11-06 用户验收通过；MCP已发现，分类类型和节点的查询/新增/修改/删除已实际调用验证。

## 适用与契约

用于独立业务分类类型及分类节点管理，字段见 `Docs/API/分类管理API.md`。工具：`category_schemes`、`category_scheme_options`、`category_scheme_create`、`category_scheme_update`、`category_scheme_delete`、`category_list`、`category_options`、`category_create`、`category_update`、`category_delete`。

通用参数类型和 MCP JSON-RPC 外层示例见[织云 ERP MCP 调用指南](../MCP调用指南.md)。

## 查询调用示例

先查分类体系；再从响应复制实际体系 ID 查询对应分类树。ID 作为十进制字符串传递：

```json
{"name":"category_schemes","arguments":{}}
```

```json
{"name":"category_list","arguments":{"schemeId":"123456789012345678"}}
```

示例 ID 仅展示字符串格式，必须替换为 `category_schemes` 返回的真实 ID。

## 执行步骤

1. 查询分类类型，明确本次业务范围；未指定分类类型时先定位，不把物料/款式分类混为一棵树。
2. 查询完整节点，确认父级路径、层级限制和状态；历史可显示不等于可新增引用。
3. 写入前展示分类类型、编码、目标路径和变化。停用分类类型需说明整棵分类树不能再被新业务选择；删除分类类型需确认其下从未建立过分类节点且无业务引用，并明确提示永久删除不可恢复；确认后按员工本人权限执行。
4. 自动生成编码是可编辑建议值：根分类使用分类类型编码前缀，下级使用直接父级完整编码前缀，并按同一父级递增；保存前保留员工修改，未修改时依赖服务端类型行锁按父级重分配。规则在参数设置维护，修改前需展示新旧规则并确认。
5. 不能跨分类类型移动，不能成环或超深；删除节点仅限无业务引用叶节点并逻辑删除；分类类型仅允许物理删除空类型，批量停用子级优先，启用父级优先。
6. 超时先核实结果，部分成功逐项报告，不绕过服务端引用/权限保护。分类类型编码创建后不改。
