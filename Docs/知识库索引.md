## 一、范围（只装这 5 类，别的都不进）
1. **工艺 SOP**：每款工序标准、吊挂线路、后整顺序
2. **排产经验**：同类产品历史时长、按标签的产能参考（对应生产流程规划 4.3 历史回写）
3. **异常处理手册**：吊挂中继库掉线、ODBC 被拦、色差处理等排障经验
4. **客户特殊要求**：某品牌 AQL 标准、装箱规矩、验货习惯
5. **返修判定案例**：什么瑕疵判返修/报废、责任归哪道工序

## 二、写法规则（强制，关系到向量检索质量）
1. **一条知识 = 一个文件区块**（一个 H3 小节），不混写。检索按"条"召回。
2. **单条 ≤ 400 汉字**（embedding 模型 BGE-large-zh 上限 512 token ≈ 500 汉字，留余量）。超长条目拆成多条，用"原文ID + 序号"关联回整条。
3. 每条顶部固定头：**类别 / 款号 / 工序 / 客户 / 更新日期**（做检索元数据，可条件过滤）。
4. 术语用《术语词库索引》既定词，不自造（对应词库第二节规则）。
5. 只写"会变的业务经验"，静态流程/单据设计不进来（那在生产流程规划.md）。

## 四、与向量库的关系
- 本文档是**唯一事实源**；向量库（pgvector，建在 PostgreSQL）只是"影子索引"，存切片 embedding。
- 文档改 → 跑 `重建索引.py` 重建，向量库不是事实源。
- 见《内嵌智能体规范》"知识库与向量检索"节的 .env 配置与降级路径。
