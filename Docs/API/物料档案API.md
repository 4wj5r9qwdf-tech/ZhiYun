> 功能键：`material`；表：`inv_material`、`inv_material_color`、`inv_material_aux_unit`、`inv_material_spec_template`；状态：一期（2026-11-08）、二期（2026-11-13）用户验收通过；MCP 运行时已发现 9/9 工具。2026-11-20 用开发环境管理员认证调用物料类别/属性模板读取及临时档案新增、列表、修改、停用/启用、删除；临时档案删除后按编码回查无记录。`material_options`、`material_next_code`、普通账号权限和 SnailAI 页面确认卡尚未实际核验；本次未查阅操作日志记录。

## 字段约定

新增/修改 JSON 字段：

```json
{
  "code": "MAT00001",
  "autoGeneratedCode": "MAT00001",
  "name": "棉针织布",
  "schemeId": "分类类型ID",
  "categoryId": "分类节点ID",
  "specification": "20 × 30 cm",
  "fabricWeightGsm": "180",
  "fabricWidthCm": "160",
  "composition": "棉95%、氨纶5%",
  "model": "可选型号",
  "brand": "可选品牌",
  "materialDesc": "材质和属性说明",
  "inventoryUnitId": "库存基本单位ID",
  "materialUnits": [
    {"unitId":"盒ID","mode":"FIXED","referenceUnitId":"个ID","factor":"100","purchase":true,"usage":true},
    {"unitId":"箱ID","mode":"FIXED","referenceUnitId":"盒ID","factor":"20","purchase":true,"usage":true},
    {"unitId":"卷ID","mode":"VARIABLE","purchase":true,"usage":false}
  ],
  "colorIds": ["颜色ID1", "颜色ID2"],
  "sortOrder": 0,
  "remark": "备注"
}
```

`schemeId` 仅用于前端展示上下文，后端以 `categoryId` 反查并校验真实分类体系，不信任该字段。编码建议保持可编辑；保存时只有编码为空或仍等于页面传回的建议值才会在事务锁下重新分配，手动修改值将保留并校验唯一性。自动编码参数键为 `inventory.material.codeRule`，字段为 `enabled`、`prefix`、`digits`。

克重与幅宽分别以 g/m²、cm 为固定单位，采用十进制字符串传输。空值表示不适用。二期取消自由文本尺寸录入。尺寸使用模板字段，随独立规格变化时写入规格属性。旧 `specification` 字段为兼容保留，新调用无需提交。

`materialUnits` 保存物料专属采购及生产领用单位，库存单位默认用于两类业务，无须重复添加。`FIXED` 表示一个当前单位等于 `factor` 个 `referenceUnitId`；参照可以是库存单位或同物料的其他固定单位，服务端校验循环、精度并返回 `inventoryFactor`。`VARIABLE` 表示业务中录入实际库存数量，不提供固定系数或参照。用途 `purchase`、`usage` 至少启用一项。同一个单位只保存一次，可以同时勾选两个用途。公共换算可作为初始建议，保存后是物料自己的快照，不更改单位档案。`materialUnits` 省略且库存单位未变时保留原配置，空数组清除；变更库存单位需重新配置。旧 `auxiliaryUnitIds` 兼容公共固定关系，已有专属关系保留其系数，采购用途不会因旧客户端省略而丢失。

物料单位配置 CSV 字段为 JSON 数组，单位和参照使用 `unitCode`、`referenceUnitCode`。业务单据后续须保存所选单位、原数量、实际或固定换算及折算库存数量的历史快照；数量使用精确十进制，库存单位精度不足时禁止静默舍入。按实际数量的单位目前只是物料配置，逐卷收货、余量及领料流程尚待业务模块实现。

入库业务约定：`FIXED` 系数作为带出的默认值，入库人员可针对本次单据或明细修改实际换算系数或实际库存数量；按卷记录时允许逐卷填写实际数量。单据须明确数量、单位与实际折算结果，修改其中一项时同步重新计算并校验其余数值，避免出现不一致。入库确认保存该次采用的系数及实际数量快照，不修改物料默认系数和公共单位档案；同一单据不同明细或卷可有不同实际数量。`VARIABLE` 不预填固定系数，按实际数量录入。具体成本和数量差异处理在入库业务设计时确定。

列表展示项主要为 `id`、`code`、`name`、`schemeId`、`schemeName`、`categoryId`、`categoryName`、`specification`、`model`、`brand`、`materialDesc`、`inventoryUnitId`、`inventoryUnitName`、`inventoryUnitCode`、`materialUnits`、`auxiliaryUnitIds`、`fabricWeightGsm`、`fabricWidthCm`、`composition`、`colors`、`status`、`sortOrder`、`remark`。`auxiliaryUnitIds` 作为旧字段保留，只包含允许生产领用且与公共固定换算完全一致的单位；物料专属、链式及实际数量规则由 `materialUnits` 返回。旧客户端使用旧字段编辑时，服务端保留其无法表达的物料专属规则。

状态：`0` 启用，允许新业务选择；`1` 停用，保留历史回显，不允许新增引用。库存数量、供应批号/缸号、客户来源、质量状态、仓库库位和业务单据均不属于物料档案。

## 分类权限和安全

人员未单独配置分类范围时默认为全部可见；指定范围按人员分类授权表过滤类型/节点并可按契约包含下级；全部不可见返回空分类及空物料结果。列表先过滤后筛选，导入逐行复用新增校验，导出只导出当前列表已授权记录。新增、修改与 MCP 写入重新验证分类、启用单位、启用颜色，不以页面隐藏代替授权。

物料默认分类类型只负责初次展示定位，不改变人员授权范围；未设置时展示全部可访问类型，已设默认不可用时安全回退到全部当前授权范围。用户始终可以切换其他有权分类。

## 规格模板

新增和编辑可传 `specTemplateCode` 与 `specValues`，例如 `{"specTemplateCode":"button","specValues":{"diameter":"18","holeCount":"4"}}`。模板编码为空表示通用规格。编辑省略模板字段时沿用已保存模板和规格。清空模板或切换模板会保留原先保存的规格值，查询返回 `specTemplateCode`、`specValues` 以及兼容面料字段。客户端只提交当前模板显示的字段。空字符串或 `null` 可清空选填字段，未提交的字段保留原值。

数字按十进制字符串传输，是否字段传布尔值，选项值以目录定义为准。标准缩率字段使用 `signed_decimal`，允许 -100% 至 100%，负数表示尺寸增长。克重、幅宽和成分仍以已有面料字段为准。面料模板另外记录经向/纬向标准缩率、测试条件，以及按供应商口径填写的密度。当前预置十套模板；调用方必须先读模板目录，不得将模板清单、字段或选项写死。后续可向指定模板增加字段：使用稳定字段键，并定义标签、数据类型、单位、必填性、选项及校验；相同字段键必须语义一致。保存、切换模板和 CSV 导入不得清掉调用方未展示的既有字段。CSV 新增「规格模板编码」「模板规格值」两列，后一列为字段对象，可从导出文件复制。两版旧表头仍可导入。

物料 legacy specification 的行为已修正：新增省略时为空，更新省略保留历史值，显式 null/空白清除。修改时需带回名称、分类、单位、可选文本、排序、最终颜色集合及所有需维护的关联；单位集合省略仅在库存单位未变时保留已有关系。

### MCP arguments 示例

读取模板、单位、颜色及分类后，新增时明确提交最终关联集合。ID 与属性模板键须替换为当前目录结果：


### 多规格

物料列表和业务选项返回 `multiSpec`、`variants`。规格包含字符串 `id`、`code`、`name`、`status`（0 启用，1 停用）。业务选项只返回启用的规格，物料档案返回全部规格。新建和编辑可提交这两个字段，新增规格省略 ID，编辑规格保留原 ID。旧调用省略 `multiSpec` 时保留原配置。已保存规格通过停用退出选料。

款式 BOM 用料明细通过 `materialVariantId` 引用实际物料规格。多规格物料保存 BOM 时必须选择启用的本档案规格。需求试算按物料、规格、颜色和库存单位分别汇总。历史版本仍可查看原记录，重新保存时按当前档案规则校验。

后续出入库单和库存台账沿用此规格 ID。启用多规格时，每条出入库明细必须指定具体规格，库存流水及余额按规格分别记录。单规格物料沿用空规格 ID。

物料档案列表返回 `variantFields`（当前属性模板中按规格填写的字段键）和每条规格的 `attributes`。调整字段归属时同时提交 `multiSpec`、`specValues`、`variantFields` 和完整的 `variants`。已设为按规格填写的字段由服务端清除共用值，启用规格必须填写这些属性，停用规格可留空。规格 ID 保持稳定。

物料规格编码在同一物料档案内不区分大小写唯一。不同物料可以使用相同的规格编码，业务引用使用规格 ID。
