# 仓库布局 API / MCP 契约

> 功能英文名：`warehouse_layout`；位置数据表：`inv_warehouse_location`；用户验收：2026-11-05 通过。
> REST：已实现。MCP：只读、位置 CRUD、状态、规则维护和逐条结果的批量新增均已接入 `/mcp`，本轮 `tools/list` 已发现。CSV 文件仍由调用方解析为位置对象数组；批量写入逐条提交，允许部分成功。
> 库区/货架/货位是一个仓库布局功能内的三级位置；`location_level` 分别为 1/2/3。AGV 字段只记录能力及外部映射，本功能不执行调度。

## 1. 通用约定

- 使用当前员工自己的 Sa-Token 会话；MCP `/mcp` 校验有效 token、匹配 `clientid` 和客户端访问范围。所有操作依权限码执行，不允许超管代办。
- ID 使用十进制字符串，避免 bigint 精度损失。REST 统一响应：`{"code":200,"msg":"操作成功","data":...}`；业务失败为 `code=500`、`data=null`。无权限为 `403`，登录/客户端校验失败为 `401`。
- 状态：`active`启用、`disabled`停用、`maintenance`维护。编码按仓库—库区—货架—货位逐级拼接；自动生成的建议用户可以编辑。未修改建议值时，服务端在仓库锁内重新分配。
- 写入不提供幂等键。超时后先查询核对，不能盲目重试新增或批量导入。

## 3. REST 接口

### 仓库选项 — `GET /system/warehouse-location/options`

无需参数。返回仓库 ID、编码、名称、`inbound_location_level`、状态；包含停用仓库以便历史查看。机器契约：幂等只读；无副作用；已登录即可；无需审批。

### 位置树 — `GET /system/warehouse-location/tree`

可选 `warehouseId`；不传读取全部仓库。返回嵌套树，节点含位置/仓库/父级信息、层级、状态、容量和 AGV 字段。机器契约：幂等只读；无副作用；需要 `inventory:location:list`；无需审批。

### 位置列表 — `GET /system/warehouse-location/list`

必填 `warehouseId`；可选 `parentId`、`level`（1–3）、`keyword`（编码/名称/外部映射码）、`status`（`active`、`disabled`、`maintenance`）。层级或状态不符合枚举时返回参数错误。机器契约：幂等只读；无副作用；仓库和父级必须有效且同属该仓；需要 `inventory:location:list`；无需审批。

成功数据项示例：

```json
{"location_id":"5001","warehouse_id":"1001","parent_location_id":null,"location_code":"WH0001-Z01","location_name":"面料区","location_level":1,"agv_reachable":true,"capacity_limit":null,"capacity_unit":null,"location_status":"active","external_location_code":null,"remark":"","warehouse_code":"WH0001","warehouse_name":"一号仓","parent_location_code":null,"parent_location_name":null}
```

### 位置详情 — `GET /system/warehouse-location/{id}`

路径参数 `id` 为位置 ID。返回位置字段及父级编码/名称。机器契约：幂等只读；无副作用；记录存在且有 `inventory:location:query`；无需审批。

### 编码建议 — `GET /system/warehouse-location/next-code`

必填查询参数：`warehouseId`、`locationLevel`；可选 `parentLocationId`（库区不传）。返回 `data` 字符串建议。机器契约：幂等只读；无副作用；仓库与父级层级有效、自动编码开启且有 `inventory:location:add`；无需审批。

### 新增位置 — `POST /system/warehouse-location`

```json
{
  "warehouseId":"1001",
  "parentLocationId":null,
  "locationLevel":1,
  "locationCode":"WH0001-Z01",
  "autoGeneratedCode":"WH0001-Z01",
  "locationName":"面料区",
  "agvReachable":true,
  "capacityLimit":1000,
  "capacityUnit":"卷",
  "locationStatus":"active",
  "externalLocationCode":"AGV-Z01",
  "remark":""
}
```

库区直接归仓库；货架必须归库区；货位必须归货架。所属仓库、层级和父级建立后不可移动。用户可以改 `locationCode`；若与 `autoGeneratedCode` 相同，服务端保存时重新分配建议。

机器契约：非幂等；副作用为新增仓储位置及业务审计；前置为 `inventory:location:add`、仓库启用、父级存在且启用、层级正确、编码在仓库内唯一；无需审批，执行前展示仓库/父级/类型/编码/名称并取得员工确认。成功 `data` 为最终位置编码字符串。

### 编辑位置 — `PUT /system/warehouse-location`

新增字段外需 `locationId`。编码、仓库、父级和层级不可改变；编辑名称、AGV 能力、容量、状态、外部映射码和备注。

机器契约：目标状态幂等但会写审计；副作用为更新位置字段及业务审计；前置为 `inventory:location:edit`、记录有效且父子状态约束通过；无需审批，执行前确认具体变更。

### 启停/维护 — `PUT /system/warehouse-location/{id}/status`

请求体：`{"locationStatus":"maintenance"}`。值为 `active`、`disabled` 或 `maintenance`。机器契约：状态幂等；副作用为变更状态并写审计；前置为 `inventory:location:edit` 且父子状态约束通过；无需审批，执行前确认。父级状态不可与有效子级冲突。

### 删除位置 — `DELETE /system/warehouse-location/{id}`

机器契约：非幂等；副作用为逻辑删除位置并写审计；前置为 `inventory:location:remove`、没有未删除子级、没有业务单据外键引用；无需审批，但必须展示完整位置路径并取得员工确认。受引用位置应停用，不得绕过限制。

### 自动编码规则

- 读取固定参数：`GET /system/config/configKey/inventory.warehouseLayout.codeRule`；仅允许读取此固定键，勿开放通用任意参数读取工具。该接口没有单独 `@SaCheckPermission`，仍须登录并受全局客户端访问范围约束。
- 保存：`POST /system/config/warehouse-layout-code-rule`，权限 `system:config:edit`。请求示例：`{"enabled":true,"zonePrefix":"Z","zoneDigits":2,"rackPrefix":"R","rackDigits":2,"binPrefix":"B","binDigits":3}`。前缀为 1–8 位字母/数字，位数 1–6。
- 保存规则机器契约：相同规则值幂等；副作用为写入 `inventory.warehouseLayout.codeRule`、业务审计和清除缓存；无需审批，但智能体先展示完整新旧规则并等待确认。此配置不改变已有编码。

## 4. 错误及导入边界

常见业务错误包括仓库停用/不存在、父级跨仓或层级不符、父级停用、编码重复、父子状态冲突、仍有子级或已被单据引用。保留服务端中文错误原因，不自动改码或递归删除。

CSV 文件由调用方解析成规范位置对象后，可调用 `warehouse_layout_batch_create`。每一行分别执行仓库/父级/层级/编码校验、事务和业务审计；行与行之间不组成单一事务，因此可能部分成功。返回结果会标出每行的最终编码或失败原因；连接异常行应先查询核实，不能盲目重试。

## MCP 字段矩阵（契约迁移批次 1）

warehouse_layout_create、warehouse_layout_update 的 body 和批量工具 rows[] 都是 Map<String,Object>。运行时 schema 只约束参数外层对象/数组，不校验内部字段；下表递归列出服务端实际读取的业务键。除特别说明外，字符串先 trim，null、空白字符串和省略可能触发不同默认值。未知键不使用。

| 字段路径 | JSON 类型 / 格式 / 示例 | 必填与省略结果 | null / 空白 / 空集合结果 | 用途、来源、校验与副作用 |
|---|---|---|---|---|
| body.warehouseId / rows[].warehouseId | string 十进制 ID；"1001" | 新增必填；缺失或无法解析则拒绝 | null/空白解析为无效并拒绝；数组/对象不适用 | 从仓库选项复制在用仓库 ID；批次行各自独立校验 |
| body.parentLocationId / rows[].parentLocationId | string 十进制 ID 或 null；"5001" | 库区省略；货架/货位必须提供有效父级 | null/空白解析为 null；库区应如此；货架/货位会因缺父级而拒绝；空集合不适用 | 货架父级须为同仓库库区，货位父级须为同仓库货架；来源于位置树/列表 |
| body.locationLevel / rows[].locationLevel | integer；1 | 必填；省略或无法解析拒绝 | null/空白无法解析并拒绝；数组/对象不适用 | 1库区、2货架、3货位；决定父级层次及编码前缀 |
| body.locationCode / rows[].locationCode | string；"WH0001-Z01" | 新增必填；自动编码开启时可空，服务端分配建议；关闭时必填 | null/空白视作空编码；等于 autoGeneratedCode 时锁内重新分配；数组/对象不适用 | 仓库内不区分大小写唯一，最多 80 字符；自动编码建议可编辑 |
| body.autoGeneratedCode / rows[].autoGeneratedCode | string；"WH0001-Z01" | 可选；省略不参与建议值比较 | null/空白不参与比较；空集合不适用 | 原样带回 warehouse_layout_next_code 的建议值；只有用户未编辑建议时重新取号 |
| body.locationName / rows[].locationName | string；"面料区" | 必填；省略、null、空白均拒绝 | 空白 trim 后拒绝；数组/对象不适用 | 位置名称，最多 200 字符 |
| body.agvReachable / rows[].agvReachable | boolean；true | 可选；省略或 null 默认为 true | 空白字符串不属于合法布尔输入；空集合不适用 | 是否标记 AGV 可达；该字段只记录能力，不触发 AGV 调度。Map 转换会把除 "true" 外的非空文本解析为 false，调用方必须传 JSON boolean |
| body.capacityLimit / rows[].capacityLimit | number 或十进制 string；1000 | 可选；省略/null/空白表示无容量上限 | null/空白清空容量；非数字或负数拒绝；空集合不适用 | 容量上限；有值时 capacityUnit 必须同时非空 |
| body.capacityUnit / rows[].capacityUnit | string；"卷" | 可选；容量有值时必填 | null/空白转为无单位；有容量上限时拒绝；最多 30 字符 | 容量数量对应的业务单位，由员工确认，不自动换算 |
| body.locationStatus / rows[].locationStatus | string 枚举；"active" | 可选；省略/null/空白默认为 active | 空白等同默认启用；其他非法值拒绝；空集合不适用 | 取 active启用、disabled停用、maintenance维护；父子状态约束再次校验 |
| body.externalLocationCode / rows[].externalLocationCode | string；"AGV-Z01" | 可选 | null/空白表示无外部映射码；最多 120 字符 | 外部系统位置码；同一仓库内不区分大小写唯一 |
| body.remark / rows[].remark | string；"近门侧" | 可选 | null/空白保存为空；最多 1000 字符 | 备注；不承载 AGV 调度指令 |
| warehouse_layout_batch_create.rows | array<object>；见下方完整示例 | 必填，1–1000 行；缺失、null、空数组或超限拒绝整个请求 | 空集合拒绝；null 行作为该行失败结果返回；行内字段按上列逐条校验 | 每行各自事务和审计，可能部分成功；网络异常先回读结果，不能盲目重放整批 |
| warehouse_layout_update.body.locationId | string 十进制 ID；"5001" | 必填；缺失或无效返回失败 | null/空白拒绝；数组/对象不适用 | 从位置详情复制；更新目标须可见 |
| warehouse_layout_set_status.locationId | string 十进制 ID；"5001" | 必填；省略/空白拒绝 | null拒绝；空白状态会被控制器默认成 active，因此调用方必须显式传目标枚举 | 写状态前先读取路径及当前状态；通过 MCP 包装为 locationStatus |
| warehouse_layout_set_status.locationStatus | string 枚举；"maintenance" | 必填；只能是 active、disabled、maintenance | null 可能触发参数构造异常；空白会回退 active，故不得传空白；数组/对象不适用 | 目标状态；停用/维护须遵守父级/子级状态约束 |
| warehouse_layout_set_code_rule.rule.enabled | boolean；true | 必填；省略/null 拒绝 | 空白不适用；数组/对象拒绝 | 是否启用自动建议；参数修改影响以后新增位置 |
| rule.zonePrefix、rule.rackPrefix、rule.binPrefix | string；"Z" / "R" / "B" | 三项均必填；1–8 位英文字母或数字 | null、空白或其他符号拒绝 | 分别是库区、货架、货位编码段前缀；保存后转大写 |
| rule.zoneDigits、rule.rackDigits、rule.binDigits | integer；2 / 2 / 3 | 三项均必填；1–6 整数 | null、空白、小数或越界值拒绝 | 分别设置各层序号补零位数；不能把一层规则误当成全局统一位数 |

修改位置时，控制器仍会写入名称、AGV 标志、容量、单位、状态、外部映射码及备注；省略或 null 可能分别重置为默认值或清空字段。调用方须先读详情并提交上述可编辑字段的完整最终值。warehouse_layout_update 虽名为 update，不应把它当增量补丁。
