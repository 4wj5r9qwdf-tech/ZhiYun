# 颜色管理 API 与 MCP 契约

> 版本：v1
> 更新日期：2026-11-07
> 说明：用户于 2026-11-07 确认颜色管理验收通过；REST 与 MCP 工具已接入。表 `base_color`，功能键 `color`。
> 契约迁移：2026-11-21 已补 MCP 字段矩阵，并收紧自由 Map 的字段白名单、字段类型与修改完整性校验；运行时真实调用和权限复核仍按下方状态记录。

## 一、公共规则

认证、请求头和 `code/msg/data` 响应结构沿用[API 总索引](API文档.md)。所有 bigint ID 以十进制字符串传输。色值仅用于屏幕辅助辨认，格式为 `#RRGGBB`；空值表示未维护色样，不能替代实物色卡或供应商色号。

| 方法与路径 | 用途 | 权限 | 幂等/副作用/前置 |
|---|---|---|---|
| GET `/system/color/list` | 管理目录全量查询 | `system:color:list` | 只读；页面在完整结果集筛选分页 |
| GET `/system/color/options` | 业务颜色选项，包含停用项和 `selectable` | 已登录 | 只读；停用项仅用于历史显示，不可新选 |
| GET `/system/color/next-code` | 获取下一条颜色编码建议 | `system:color:add` | 只读预览；自动生成关闭时返回空编码；保存仍由服务端重新分配未修改的建议 |
| POST `/system/color` | 新增颜色 | `system:color:add` | 非幂等；写档案与业务审计；编码/名称唯一；智能体须先确认 |
| PUT `/system/color/{id}` | 修改颜色显示信息 | `system:color:edit` | 编码创建后固定；写审计前后值；智能体须先确认 |
| PUT `/system/color/{id}/status` | 启用或停用 | `system:color:edit` | 停用阻止新引用，保留历史显示；写审计；智能体须先确认 |
| DELETE `/system/color/{id}` | 删除未被外键引用的颜色 | `system:color:remove` | 物理删除；有任何外键引用时拒绝并建议停用；不可恢复，须先确认 |
| POST `/system/color/code-rule` | 修改颜色自动编码规则 | `system:config:edit` | 更新系统参数 `base.color.codeRule`，记录规则变更 |

## 二、字段

| 字段 | 类型/必填/默认 | 中文说明 / English |
|---|---|---|
| `id` | string，系统生成 | 颜色稳定主键，跨模块引用使用此 ID / Stable color ID |
| `code` | string，新增必填，最多40 | 颜色编码；自动建议可编辑，创建后不可修改；忽略大小写唯一 / Editable suggested color code |
| `autoGeneratedCode` | string，新增可选 | 页面展示的原始建议值；若提交值未修改，服务端按事务锁重新分配避免并发重复 / Original suggestion for safe reallocation |
| `name` | string，必填，最多80 | 颜色名称，忽略大小写全局唯一 / Color name |
| `color_value` | string，可选 | 屏幕色样，空或 `#RRGGBB` / Optional display swatch |
| `sort_order` | integer，可选，默认0，0–999999 | 显示排序 / Display order |
| `status` | string，可选，默认`0` | `0`启用、`1`停用 / Availability |
| `remark` | string，可选，默认空，最多500 | 补充说明；不填供应商色号、缸号和库存批次 / Notes |

新增请求：

```json
{"code":"CLR0001","autoGeneratedCode":"CLR0001","name":"藏青","color_value":"#1F2A44","sort_order":10,"remark":""}
```

成功返回 `{"code":200,"msg":"操作成功","data":"颜色ID字符串"}`。列表和选项 `data` 为对象数组；选项额外包含 `selectable:boolean`，停用记录为 `false`。

## 三、编码规则

参数键 `base.color.codeRule`，默认值 `{"enabled":true,"prefix":"CLR","digits":4}`。系统管理 → 参数设置可修改自动生成开关、前缀和1–10位序号。自动生成仅提供可编辑建议；页面传回未修改的 `autoGeneratedCode` 时，后端在事务 advisory lock 内根据现有编码重新分配。用户修改后的编码按全局唯一索引校验。关闭自动生成时新增必须手工填编码。

## 四、删除、停用及业务引用

- 颜色基础档案自身没有库存、供应商色号或缸号；这些字段属于物料、供应和库存批次。
- 业务通过稳定 `color_id` 引用颜色。停用只禁止新引用；已有物料配置和历史业务仍可读取名称、色值快照。
- 删除只允许未被任何外键引用的记录。未来物料颜色关联表应使用 FK 保护；已有引用应停用，不得级联删除。
- 名称、色值或排序修改记录实际字段前后值；编码固定，避免下游识别漂移。
- 列表状态列直接启停，操作列只放编辑和删除。导入逐条调用新增接口，部分成功结果可下载失败行重试。

## 五、MCP 与审计状态

| MCP 工具 | 权限 | 用途与安全要求 |
|---|---|---|
| `color_list` | `system:color:list` | 查询颜色管理目录 |
| `color_options` | 已登录 | 查询业务选项；停用项带 `selectable=false`，仅供历史显示 |
| `color_next_code` | `system:color:add` | 获取可编辑编码建议 |
| `color_create` | `system:color:add` | 新增颜色；展示完整字段并取得本次员工确认 |
| `color_update` | `system:color:edit` | 修改名称、色值、排序、备注；编码固定，先展示差异并确认 |
| `color_set_status` | `system:color:edit` | 启停颜色；说明停用对新引用的影响并确认 |
| `color_delete` | `system:color:remove` | 物理删除无外键引用颜色；展示身份并确认 |
| `color_set_code_rule` | `system:config:edit` | 修改自动编码规则；展示新旧规则并确认 |

MCP 直接调用现有 `ColorController`，并在工具入口显式复核员工权限；写操作复用 REST 校验和业务审计，不绕过服务层。所有 ID 使用十进制字符串。2026-11-07 已核验8个工具均可发现，目录/选项/编码建议、新增/修改/启停/删除通过实际 MCP 调用；新增返回 ID 位于 `data`，临时记录已清理，审计保留。编码规则更新工具已发现，但本轮未改动实际规则；普通低权限角色写入拒绝尚未做真实账号核验，详细记录见[测试与验收清单](../项目记录/测试与验收清单.md)。

REST 和 MCP 写操作均记录具体颜色 ID、名称/编码、动作及变更字段；凭据不进入审计。

## MCP 输入字段矩阵（契约迁移批次 1）

`color_create.body`、`color_update.body` 和 `color_set_code_rule.body` 在 inputSchema 中是 object；适配器会校验允许键、必填键及 JSON 类型。未知字段拒绝。下表覆盖工具顶层参数与对象内部字段。

| 字段路径 | JSON 类型 / 示例 | 必填与省略结果 | `null` / 空白 / 空集合结果 | 用途、来源、约束与副作用 |
|---|---|---|---|---|
| `color_list`、`color_options`、`color_next_code.arguments` | object；`{}` | 无参数 | 不适用 | `color_list` 需 `system:color:list`；`color_options` 需登录；`color_next_code` 需 `system:color:add`。查询结果仅代表当前员工权限可见数据 |
| `color_create.body` | object；见下方示例 | 必须有对象及 `name` | null/空对象拒绝 | 新增颜色；非幂等，无幂等键；规则只影响未修改建议码的新建，不会修改已有编码 |
| `color_create.body.code` | string；`"CLR0001"` | 可选；省略或空值在自动编码开启时分配；关闭时必填 | 显式 null/空白按未填写处理；非字符串拒绝 | 从 `color_next_code` 取得可编辑建议；支持字母数字开头及 `_.-`，最多40字符，全局不区分大小写唯一 |
| `color_create.body.autoGeneratedCode` | string；`"CLR0001"` | 可选；省略表示没有建议值可比较 | null/空白视为未提供；非字符串拒绝 | 原样回传 `color_next_code.code`；当 `code` 与建议相同且规则开启时，服务端在锁内重新分配 |
| `color_create.body.name` | string；`"藏青"` | 必填；省略/null/空白拒绝 | trim 后不能为空，最多80字符 | 颜色全局名称，不区分大小写唯一 |
| `color_create.body.color_value` | string；`"#1F2A44"` | 可选；省略表示无色样 | null/空白清除；非空只接受 `#RRGGBB` 六位十六进制 | 屏幕辅助识别，服务端转大写；不是供应商色号或实物色卡 |
| `color_create.body.sort_order` | integer；`10` | 可选；省略默认0 | null/空白/非整数拒绝；范围0–999999 | 列表显示排序 |
| `color_create.body.remark` | string；`"深蓝色样"` | 可选；省略为空 | null/空白清除；最多500字符 | 补充说明 |
| `color_update.id`、`color_set_status.id`、`color_delete.id` | string 正十进制 ID；`"101"` | 必填；从 `color_list` 或对应返回复制 | null/空白/JSON 数字/非正 ID 拒绝 | 不转换为 number；不得猜 ID |
| `color_update.body` | object；包含下列4个字段 | 四字段必须全部提交：`name`、`color_value`、`sort_order`、`remark` | null/空对象/缺字段拒绝；编码相关字段和未知键拒绝 | 完整替换可编辑显示字段；不可只交变化字段。更新编码不支持，误传将报错 |
| `color_update.body.name` | string；`"藏青色"` | 必填；非空且最多80字符 | null/空白拒绝 | 颜色全局名称，不区分大小写唯一 |
| `color_update.body.color_value`、`remark` | string；`"#1F2A44"` / `"新备注"` | 必须显式提交 | null/空白清除；色值非空时须符合 `#RRGGBB`；备注最多500字符 | 更新时要保留现值必须从 `color_list` 回填；null/空白用于明确清空 |
| `color_update.body.sort_order` | integer；`10` | 必填 | null/空白/非整数拒绝；范围0–999999 | 排序；需要保持现值时回填当前值 |
| `color_set_status.status` | string；`"1"` | 必填；只能传 `"0"` 启用或 `"1"` 停用 | null/空白/数字拒绝 | 停用阻止业务新引用但保留历史显示；重复设置相同状态无数据变化 |
| `color_set_code_rule.body.enabled` | boolean；`true` | 必填；完整规则必传 | null/缺失拒绝 | 开启后影响后续未手填编码的新建，不改已有记录 |
| `color_set_code_rule.body.prefix` | string；`"CLR"` | 必填；trim 后非空，最多30字符 | null/空白拒绝 | 仅字母、数字、下划线、点和短横线；新建编码建议前缀 |
| `color_set_code_rule.body.digits` | integer；`4` | 必填；范围1–10 | null/数字字符串/小数拒绝 | 编码尾部序号位数；规则对象必须恰有 `enabled/prefix/digits` 三个键 |

颜色管理权限：新增 `system:color:add`，编辑/启停 `system:color:edit`，删除 `system:color:remove`，改规则 `system:config:edit`。删除有任意外键引用的颜色将被拒绝且不可改为自动解除引用。

### MCP `arguments` 示例

```jsonl
{"name":"color_list","arguments":{}}
{"name":"color_create","arguments":{"body":{"code":"CLR0001","autoGeneratedCode":"CLR0001","name":"藏青","color_value":"#1F2A44","sort_order":10,"remark":"颜色契约示例"}}}
{"name":"color_update","arguments":{"id":"101","body":{"name":"藏青色","color_value":null,"sort_order":10,"remark":""}}}
{"name":"color_set_status","arguments":{"id":"101","status":"1"}}
{"name":"color_delete","arguments":{"id":"101"}}
{"name":"color_set_code_rule","arguments":{"body":{"enabled":true,"prefix":"CLR","digits":4}}}
```

示例 ID 仅示意格式。实际调用须替换为当前查询返回的 ID，更新示例中的 null/空字符串表示明确清空；编码规则修改会影响后续新建，需展示完整新旧规则。
