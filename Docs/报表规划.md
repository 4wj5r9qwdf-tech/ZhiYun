# 报表规划（统一报表配置引擎 + 现状清单）

> 版本：v1（现状统计 + 自定义报表配置器，2026-10-23）
> 说明：织云 ERP 全模块"哪些地方会出报表/统计/看板"的现状清单 + 统一报表引擎设计 + **后台自定义报表配置器（手搓报表）**。来源 = 逐模块翻需求文档统计。**后续你有新报表想法再加**，本文件是登记处。

---

## 一、设计原则（你已拍板）
1. **汇总/明细 = 同一功能页内切换**（表格顶部"汇总 ▾ / 明细 ▾"切换器），**不单开两个入口**；同一数据源、同一筛选，切换只改聚合粒度。汇总行可"下钻"到该行明细。
2. **统一报表配置引擎**：一张"报表定义"配置表，加报表=插一条记录、改配置不改代码（踩"不重复造轮子"）。每个报表定义描述：数据源 + 汇总维度（groupBy）+ 明细字段 + 筛选（复用列表页筛选）+ 周期 + 合计行口径。
3. 汇总/明细切换、下钻、合计行（随筛选重算）、导出 Excel，全在引擎一次做好；各模块报表只配数据源和维度。
4. 报表抬头公司名/logo 跟单据"归属公司"（前端规范 A.0 业务层），不随展示公司切。
5. **后台自定义报表配置器（手搓报表，独立功能入口）**：系统里做一个"新建报表"页面，让运营/文员**在后台自己配一张报表**（选数据源→选汇总维度→挑明细字段→设筛选→选周期→切汇总/明细），**保存即出报表，不找开发、不改代码**。配置存"报表定义表"，与第二节那些系统预置报表**共用同一张定义表**（预置报表=开发预插的几条定义，自定义=后台插的新定义，同一套引擎渲染）。

## 三、后台自定义报表 的能力边界（定稿 2026-10-23，先说清免得误解）

报表配置引擎做完后，**后台能对"已登记的数据源"做自定义报表**（选汇总维度、挑明细字段、设筛选、切汇总/明细），但**不是"后台随便填 SQL 建任意报表"**。两条边界：

1. **数据源白名单（安全优先，同 预警 结构化 原则）**
   - 引擎只允许从**已注册的表/视图 + 已登记的列**里拼数据，**后台用户不填自由 SQL**（防注入/防乱查）。
   - 想自定义"已有业务数据"的报表（产量/费用/考勤…）→ 随便配，够用。
   - 想要"系统还没有这张表/这个字段"的报表 → **先建那个业务数据（表），再登记进数据源白名单**，引擎才认得。
   - 登记表 `report_datasource`（数据源白名单）：登记"哪张表/视图 + 哪些列可被报表查 + 汇总度量列（可求和/可平均）"，跟 `alert_field_whitelist` 同一套安全思路。

2. **复杂跨表口径 = 预置视图（开发侧）**
   - 引擎对"单表 + 简单 groupBy"最强；需要多表 JOIN 的复杂口径（如"订单成本=面辅料+工时+分摊"），**由开发预先写好 SQL 视图并登记成数据源**，后台再基于该视图配维度/筛选。
   - 后台用户**不直接写 JOIN**，但能用上开发预置的复杂视图。

**一句话**：引擎做完 = 后台能对已登记数据源自定义 汇总/明细 报表；需要新数据先建表、需要复杂关联先预置视图（这两步是开发侧，不是后台填 SQL）。

### 自定义报表配置器（后台手搓，"报表中心 → 新建报表"）
这是**一个独立功能入口**（挂 报表中心/系统 模块，按角色权限门控），运营/文员在后台自己配一张报表，不用找开发：

| 步骤 | 后台操作 | 落到"报表定义表"的字段 |
|---|---|---|
| 1 选数据源 | 从已登记数据源（`report_datasource` 白名单）里选 | `datasource_id` |
| 2 选汇总维度 | 勾选 groupBy 列（订单/组/天/车间…） | `group_by`（多选） |
| 3 选度量列 | 选要聚合的数值列 + 聚合方式（求和/平均/计数/最值） | `measures` |
| 4 挑明细字段 | 展开到行级显示哪些列 | `detail_fields` |
| 5 设筛选 | 复用列表页筛选（表/字段/操作符/值，结构化） | `filters` |
| 6 选周期 | 日/周/月/自定义区间 | `period` |
| 7 定汇总/明细 | 同页切换器（一、原则 1） | `view_mode` |

- **保存 = 往"报表定义表"插一条记录**，引擎按定义渲染（跟第二节系统预置报表同一套渲染，不各写一套）。
- 配好的自定义报表出现在该角色能看到的"报表中心"列表，可看、可导出、可分享链接。
- **前提成立**：只要**数据源给得够全够清晰**（白名单表/视图登记到位、度量列标好哪些能求和/平均），后台手搓就能覆盖大部分日常报表；碰到没有的数据才退回"先建表/先预置视图"（开发侧）。
- 权限：谁能配自定义报表 = 角色权限（默认给 文员/领导，车间工人只看不配）；配出的报表可见范围也挂角色。
