# 模块-车辆

> 版本：v1（定稿）
> 更新日期：2026-10-23
> 说明：织云 ERP 车辆管理模块（厂区公车，仅几辆，无送货车）。地基引用 地基/审批与预警、地基/属性标签（车辆.前缀）。费用走财务报销，本模块只做登记、报财务时财务引用单据。

---

## 〇、范围
- 厂区**公车**（公务小汽车/通勤等），**不含送货货车**（送货归 货运物流，另一条线）。
- 现状就几辆，管理从简，不做"派车/抢车"那种复杂调度。

## 一、车辆台账
- 车牌号 / 车型 / 所属 / 驾照人（挂员工ID）/ 状态（在用/维修/报废/封存）/ 车辆标签（`车辆.通勤班车`/`车辆.公务`…，走 地基/属性标签）

## 二、领用（不是派出）
- **领用**：某员工领用某车（领用单：用车人、车牌、起止、事由），登记即可，**不做"派车/调度"**。
- 用车人/驾照人挂员工ID（同地基规则，历史可查）。

## 三、记录（这几项各一张单）
| 单 | 内容 | 关联财务 |
|---|---|---|
| 车辆状态 | 在用/维修/报废/封存 变更，留痕 | — |
| 审车 | 年检/审车记录，到期**走预警** | — |
| 加油 | 加油单（日期/升数/金额/油价） | 走财务报销 |
| 保养 | 保养/维修单（项目/金额/供应商） | 走财务报销 |
| 违法处理 | 违章记录（车牌/时间/类型/金额/处理状态） | 走财务报销 |

## 四、与财务的边界（你定的"分开"）
- **车辆模块只做登记**：领用/状态/审车/加油/保养/违法，把"花了多少钱"记清楚、**单据化**。
- **报财务时**：财务那边**引用本模块的单据号**，走财务的**报销流程**（不是车辆模块直接扣钱/记账）。
- 即：**车辆 = 登记 + 出单据；财务 = 引用单据 + 报销审批**。两条线，界面/职责分开。
- 哪些单走财务审批：加油/保养/违法处理 这些**花钱的单 → 走审批（财务报销审批）**（你定的"审批主要是走财务的走审批"）。

## 五、提醒/预警
- 审车到期、车辆维保到期 → 走统一预警（可配提醒对象）。
