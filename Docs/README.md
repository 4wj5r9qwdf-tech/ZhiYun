## 事实来源和维护

- 业务规则以用户最新确认及对应规划、地基文档为准；同一规则只保留一个权威来源，其他文档链接回该来源。
- 当前实现以代码、数据库和实际运行状态核实；[项目记录](项目记录/功能实现状态.md)是状态导航，不代替代码和验收证据。
- 工程流程遵循 [AGENTS.md](../AGENTS.md) 的协作入口及 [开发规范](规范/开发规范.md) 等专题文件。
- 归档、技术参考、AI 规划和旧任务记录中的状态可能过期。对外说明或实施前应核对当前代码、授权及运行状态。
