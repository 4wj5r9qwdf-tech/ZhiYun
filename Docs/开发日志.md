  - **OSS 默认桶踩坑 + 公司logo/登录背景图破图根治（2026-10-25，本次）**：
    - 现象：公司档案上传的 logo/登录背景图 `<img>` 破图（登录页/档案页都不显示）。
    - 根因：Redis 全局默认 OSS 配置 `global:sys_oss:default_config` = `minio-private`（私有桶）。RuoYi `SysOssConfigServiceImpl.init()` 启动时把每个 `status=Y` 的配置都覆盖该 key，`minio-private` 排序在后且 status=Y → 启动后默认变私有桶 → 所有走 `/resource/oss/upload`（`OssFactory.instance()`）的上传都落私有桶，公开资源（logo/背景）直连 403 破图。
    - 根治：`sys_oss_config` 里 `minio-private` status 改 **N**（不再当默认；私有桶仍可被 `PrivateFileController` 显式 `instance("minio-private")` 调用，不依赖默认）。重启后 init 重载 → 默认=`minio`（公开桶）。**铁律：私有桶绝不能设为 status=Y（会抢默认），只留公开桶 minio=Y。**
    - 数据：把误入私有桶的 logo/背景图复制到公开桶 `zhizhun-files` + 更新 `sys_oss`（service=minio, file_name/url 指公开桶）。
    - 登录页背景铺满：CSS `.brand-bg` 用 `background-size:cover`（兜底铺满任意尺寸原图），mode-A 铺左侧品牌区 / mode-B 铺整页——之前不显示纯因破图，数据修好即自动铺满。
