## 三、将来可能的运营侧统筹点（预留，不做）

> 以下为预留方向，厂里有明确需求再立项；当前**不做、不建表、不建页面**。

1. **全厂后勤成本一张表**：宿舍（赔偿/补领）+ 食堂（补贴）+ 车辆（油费/保养）+ 物业（水电/报修）的费用汇总视图，**数据源 = 各模块已登记单据**，本模块只做"读 + 汇总"，不接管各模块单据。
2. **全厂场地/资源联合调度**：车位 + 宿舍床位 + 食堂包间 的联合占用视图（避免"车位给了A、宿舍也给A、食堂包间又给A"的跨模块冲突），本模块只做"读 + 提示"，不接管各模块分配单。
3. **后勤人员排班统筹**：清洁/保安/宿管/食堂 的排班统一视图，本模块只做"读"，不接管各模块排班单。
4. **外包/承包人统一档案**：食堂承包人 + 物业承包人 + 车辆维修供应商，本模块只做"读 + 汇总"，档案主数据仍归各模块/供应商档案（见《模块-财务与采购.md》一、供应商档案）。
