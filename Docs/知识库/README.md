# 向量知识库内容规范

本目录保存适合检索的动态业务经验。项目文档总入口见 [Docs/README.md](../README.md)；系统和生产流程设计见 [规划目录](../规划/README.md)。

## 一、收录范围

只收录会随工厂实践变化、可复用的业务经验：

1. **工艺 SOP**：款式工序标准、吊挂线路、后整顺序。
2. **排产经验**：同类产品历史时长、按标签维护的产能参考。
3. **异常处理手册**：设备或中继库掉线、ODBC 连接异常、色差处理等排障经验。
4. **客户特殊要求**：客户的 AQL 标准、装箱规则、验货习惯。
5. **返修判定案例**：瑕疵的返修或报废判断，以及责任工序归属。

静态流程、单据设计、字段定义和系统规范留在对应的规划、地基或规范文档，不重复录入向量知识库。

## 二、知识条目写法

1. 一条知识使用一个 H3 小节，避免把多条经验混写。
2. 单条控制在 400 个汉字以内；较长内容按“原文 ID + 序号”拆分并关联。
3. 每条顶部固定记录：类别、款号、工序、客户、更新日期，供检索和过滤使用。
4. 使用 [术语词库索引](../词库/术语词库索引.md) 中的既定词语。
5. 记录适用条件、实际做法、例外和验证结果，避免只写结论。

## 三、目录结构

知识经验按以下子目录维护：

- [工艺 SOP](工艺SOP/)
- [排产经验](排产经验/)
- [异常手册](异常手册/)
- [客户要求](客户要求/)
- [返修案例](返修案例/)

各类内容由对应子目录的 README 说明，具体经验按条目新增。

## 四、与向量库的关系

- 本目录中的 Markdown 文件是业务知识事实源；向量库（pgvector）是供检索使用的派生索引。
- 修改源文档后按项目实际知识库流程重建索引。索引脚本、部署配置和降级路径以当前代码及 AI 规范为准。
- 向量检索结果是参考依据，不能覆盖 ERP 权限、审批、业务状态校验或用户已确认的业务规则。
