# 模块-物业资产

> 版本：v1（定稿）
> 更新日期：2026-10-23
> 说明：织云 ERP 物业/资产模块。地基引用 地基/属性标签、地基/审批与预警（报修走审批、设备/资产到期走预警）。属性标签前缀 `资产.`/`物业.`。

---

## 〇、范围（你定的"要全面"）
厂区物业 + 资产 + 车位，一个模块全覆盖：
- **物业**：门禁、水电表、公共设施报修、清洁、绿化、消防
- **资产**：厂内固定资产（设备/家具/工具…）台账、领用、状态、盘点
- **车位**：车位分配/占用/费用

## 一、物业
| 子项 | 内容 | 关联 |
|---|---|---|
| 门禁 | 厂区/宿舍门禁记录、通行权限 | 只做记录+权限；设备对接完全预留、不投入（未与厂家谈，重点在生产） |
| 水电表 | 各表读数、用量、周期抄表 | **费用算钱、走付款**：抄表→用量/费用结算→付款单→财务报销/付款审批 |
| 报修 | 公共设施报修工单（报修单：位置/现象/优先级/处理人/时限） | **走审批**（小修免审/大修送审，开关）；处理结果填回 |
| 清洁/绿化 | 清洁区域、责任人、排班、记录 | 记录类，不强管控 |
| 消防 | 消防设施台账、检查/维保到期 | **走预警**（到期前提醒，复用统一预警表） |

## 二、资产
- **资产台账**：编号 / 名称 / 类别 / 原值 / 购入日期 / 归属部门 / 状态（在用/闲置/报废/盘亏）/ 位置
- **领用**：资产发给某人/某部门（领用单，挂员工ID，同"物品领用"逻辑）
- **盘点**：定期盘点（盘盈/盘亏），差异处理（走审批）
- **报废**：资产报废（走审批 + 财务）
- **类别/属性用标签**：`资产.设备`/`资产.家具`/`资产.工具`…（自由文本+常用词提示），"车间设备"直接在这挂标签（呼应你"设备也能加标签"）

## 三、车位
- **车位档案**：车位号 / 位置 / 类型（员工/公务/访客）/ 状态（空/占用）/ 使用人（挂员工ID）
- **分配**：车位分给某人/某车（关联 车辆 模块的车牌号）
- **费用**：默认**免费**；收费 = 开关（默认关），开则预留 财务/工资扣款 口子

## 四、与财务/审批/预警的接口
- 报修、资产报废、盘点差异 → **走审批**（`地基/审批与预警.md` 三、已定稿：走财务审批链，节点自定义）
- 消防/资产维保到期、水电表异常 → **走预警**（统一预警规则表，已定稿）
- 资产原值/报废残值、车位费用、**水电/网络费用** → **走财务付款/报销**（费用算钱、出付款单、走财务审批链）
- 车辆车位 ↔ 模块-车辆（车牌）

## 五、四个待确认点（已定 2026-10-23）
1. **门禁**：只做记录 + 通行权限。重点在生产模块，且尚未与门禁设备厂家谈 → 设备对接**完全预留、不投入**。
2. **水电表**：费用**要算钱、走付款**（网络费用同理）。抄表 → 用量/费用结算 → 出付款单 → 走财务报销/付款审批（同 地基/审批与预警 的财务审批链，节点自定义）。不预留"不算钱"的一期降级。
3. **资产报废残值 / 盘点差异审批级别**：走财务审批链、节点自定义、不预设几级（已定稿 `地基/审批与预警.md` 三、）；盘点差异超阈值才送审，阈值可配。
4. **车位**：默认免费；收费 = 开关（默认关）+ 预留财务/工资扣款口子。
