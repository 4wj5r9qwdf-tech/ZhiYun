## 使用规则
1. 版本号 = `V<major>.<minor>`，major 升级 = 新增独立业务模块，minor 升级 = 既有模块功能增强/缺陷修复批次。
2. 每条记录必须写清"数据库迁移内容"，与 Git 中单独提交的 DDL 提交对应（见开发规范 6.3）。
3. 发版时同步更新本文件，不允许发完版才补记录。
