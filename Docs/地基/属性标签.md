# 属性标签（地基，全模块通用）

> 版本：v1.2
> 更新日期：2026-11-02
> 说明：全模块通用的"可扩展属性"机制。业务模块不预置，模块第一次通过业务功能添加标签时自动登记归属；后续统一在标签管理中维护，不各造各的枚举。

---

## 一、核心模型

**标签 = 动态模块归属 + 自由标签名**。归属由使用标签的业务功能提供，用户只填写标签名。

```
标签记录 = [模块标识 module_key] + [模块显示名 module_name] + [手填标签名 tag_name]
         = dorm_room + 宿舍房间 + 双人
```

- **模块归属**：业务功能固定传入稳定的 `module_key` 和界面名称 `module_name`；用户不选择、不填写归属前缀。
- **标签名**：自由文本，随手加（想加"独卫""无烟""陪护"都行，不用维护大字典）。

## 二、命名空间（业务功能动态登记）

- **不预置模块清单，也不预置标签**。没有实际标签的模块不在标签管理树中显示。
- 某业务功能首次输入新标签时，`TagSelect` 将 `module_key`、`module_name` 和标签名一起提交；服务端在同一事务中幂等登记模块归属和标签档案。
- 模块标识由功能代码提供且保持稳定（如 `customer`、`prod_sample`）；显示名供标签管理树展示（如“客户档案”“样衣”）。同一模块后续传入新的显示名时同步更新目录名称。
- 标签管理树从 `sys_tag_module` 动态读取；手动新增标签仅针对已有归属。要建立新的归属，先在对应业务功能中添加第一个标签。
- `module_key` 只允许小写英文字母开头，后续可含小写字母、数字和下划线，最长 50 位；同模块内标签名不区分大小写去重，不同模块可使用同名标签。

## 三、存储与查询（不跨模块）

- 标签目录存入 `sys_tag_module`、`sys_tag`；业务记录关系存入 `sys_tag_relation`，以 `module_key + record_id + tag_id` 标识。
- **查询永远带模块标识**，标签选择值使用稳定 `tag_id`，同名标签不会跨模块串用。
- 标签只在它所属模块内生效、内筛、内统计，**不跨模块共用**。

## 四、自由文本 + 常用词提示（防同义不同词）

- 标签名自由输入（非锁死枚举）。
- 在业务功能中提交新标签后，系统自动将其纳入对应模块的标签档案，供后续提示、筛选和复用；按“module_key + 标签名”去重，不重复创建相同标签。
- 管理员可以把已有标签标记为常用，业务组件将其作为**"常用标签"下拉提示**（点一下填入，不是限制，手敲别的照样行）。下列只是业务示例，**不会随系统安装或模块登记自动创建**：
  - 宿舍常用词：双人 / 夫妻 / 独卫 / 无烟
  - 食堂常用词：荤素档 / 自助 / 清真
  - 车辆常用词：通勤班车 / 公务
- 常用词是"提示不是限制"，日常用词筛得准，特殊情况自由写。
- **目的**：全自由的最大坑是"双人/双人间/2人"同义不同词筛不到一起，常用词提示把这个坑填掉，又保留自由。

## 五、什么用标签、什么不用标签（红线）

- **属性用标签**：描述"它是什么样"的可扩展属性（双人/夫妻/独卫/清真/通勤…）→ 标签
- **结构/状态用固定字段**："它有几个/什么状态"这类骨架（床位数、空/有人/锁定、金额、日期）→ **必须固定字段，不做进标签**
  - 理由：标签是给筛选/展示的描述、可多可少；结构/状态是业务骨架（入住退房、查询、计算都靠它），模糊成标签会查不动、算不了。

## 六、各模块落地对照（引用本地基，不重造）

标签管理按已产生标签的业务归属分区：左侧树切换动态标签模块；手动新增时只能选择已有归属，编辑标签不允许迁移归属，避免破坏已有业务关联。未来功能接入时只需使用通用标签组件并传入稳定模块标识和显示名，不修改标签管理页面的模块列表或后端白名单。

业务组件选项值使用 `tag_id`，而不是标签名称；业务记录保存时以 `module_key + record_id + tag_id` 写入 `sys_tag_relation`。标签档案接口返回规范标签记录，包含 `tag_id`、`module_key`、`module_name`、`tag_name` 等字段。标签目录自动收录不等于已经建立具体业务记录关联，关联仍由对应业务保存流程完成。

下表是规划中的标签应用场景，不表示这些模块或标签会被系统预置；模块出现后仍由实际业务人员录入标签。

| 模块 | 标签归属显示名 | 用标签放什么 | 固定字段（不做进标签） |
|---|---|---|---|
| 宿舍 | 宿舍房间 | 双人/夫妻/独卫/无烟… | 房间号/楼层/床位数/床位/状态 |
| 食堂 | 食堂 | 荤素档/自助/清真… | 餐档名/档口/单价/状态 |
| 车辆 | 车辆 | 通勤班车/公务… | 车牌/车型/驾照人/状态 |
| 物品 | 物品 | 可流通/固定/易损… | 物品名/所在房间/数量/状态 |
| 客户档案 | 客户档案 | 品牌方/贸易商等客户类型提示；可自由新增 | 客户名称/编号/状态 |
| 人员信息 | 人员信息 | 员工可扩展的分类属性 | 工号/姓名/岗位/状态 |

**规则：任何新功能要"可扩展属性"，先查本文件；使用统一标签组件，首次创建标签时动态登记模块归属，不预置空模块或标签，不自建枚举、不另起一套。**
