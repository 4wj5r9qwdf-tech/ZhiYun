# 模块-财务与采购

> 版本：v1（定稿 2026-10-23，四处待确认已拍板）
> 更新日期：2026-10-23
> 说明：织云 ERP 财务模块 + 厂内采购（通用采购申请单）。地基引用 地基/审批与预警（审批/报销走审批）、地基/员工ID与工号。财务只管"钱/账"，采购申请/收货/资产入台账等动作分别归 生产/物业资产/行政 模块。

---

## 〇、边界（先定死，防巨无霸）
- **财务 = 管钱/管账**：应付、费用、报销、应收、工资、成本归集、总账对接。
- **采购/收货/资产入台账 = 各归各模块动作**，财务只"核销钱"：
  - 生产物料采购收货 → 生产流程（收货单）
  - 设备/资产（含公车）采购到验 → 物业资产（进资产台账）
  - 行政办公/耗材采购 → 行政（领用）
  - 财务是"钱最终落到哪、核销给谁"，不是"管所有采购动作"。

## 一、采购：一张通用采购申请单 + 类型分流（认可"不建独立采购体系"）
**不建重型采购模块（无询价/比价/供应商评分那套），一张通用采购申请单 + `采购类型` 字段分流**（同"通用领料单"套路，不重造）：

| 采购类型 | 收货/入账动作 | 钱归 |
|---|---|---|
| 生产物料（订单耗材/面辅料） | 到料收货（走 生产流程 收货单） | 应付 |
| 设备/资产（含公车） | 到验 → 进 物业资产 台账 | 应付（资本性） |
| 行政办公/耗材 | 收货 → 领用 | 费用 |
| （个人采购 = 走"报销"，见第三节，不算采购） | | |

- 共用：申请单结构、审批流、**供应商档案**（供应商名/资质/结算方式/联系方式/质量评级）、"到没到、花了多少"登记。
- 供应商档案全类型共用一张。


> **单据"归属公司"字段**：订单/采购申请单/报销单/发货单 每张单据带一个 `归属公司`（选 品牌档案 里的一项），**开单时定、之后锁定**；打印/报表抬头、开票主体、走哪个公司账 都读它（见 前端规范 A.0"业务层"），**不随全局展示品牌切换而变**。
## 二、报销（含"个人采购报销"）

### 2.1 报销单分类（你定的"分几类"）
- 报销类型：**差旅 / 办公 / 加油 / 其他**（可加，走 属性标签 `报销.类型` 或字典）。
- **两档挂法（你定的）**：
  - 报销单上"**可选引用 采购订单 / 入库单**"（下拉选填，非必填）：
    - **引用了订单/入库单** = 这是"买东西"类，需挂申请单/采购来路 → 走"带引用"的报销
    - **没引用（空的）** = 不需要申请、不挂订单（如纯消费/加油）→ 直接报销
  - 即同一张报销单，**"引用了就走挂申请、没引用就直接报"**，不用分两种单据类型，一张单搞定。
- **实现就一句话**：报销单加两个可空外键 `引用采购订单号`、`引用入库单号`；为空即"直接报销"，有值即"挂申请报销"。系统不硬卡，引用是"可选关联"，不是前置必填（避免给报销人添堵）。

### 2.2 审批
- **不存在免审**：所有报销**都走审批**（你定的，无小额免审）。
- **审批节点可自定义**：报销的审批链（几级、谁审、按金额/类型分走哪条链）**做成可配置**，不写死。
  - 按"报销类型 + 金额段"可配不同审批链（例：办公小额 → 1 级主管；大额 → 主管+财务+厂长）
  - 审批节点增删/调序 = 配置，不改代码（跟 地基/审批与预警 的统一引擎对齐，审批地基成套定时这里挂上）

## 三、财务各块（钱/账 边界）
- **应付**：生产物料 / 设备资产 / 行政采购 三类采购的付款核销（供应商对账、付款单）
- **费用**：行政办公、水电、维修、食堂补贴、宿舍赔偿/补领、车辆油费保养 等
- **报销**：差旅/办公/加油/其他（见二），核销挂"经手人(员工ID) + 审批链"
- **应收**：客户按订单/PO 付款（代工费 + 超交/次品扣款）
- **工资**：计件/计时 + 社保（预留扣减，见 人员管理 第九节）
- **成本归集**：订单 面辅料 + 工时 + 分摊 → 订单成本
- **总账/报表**：甩外部财务系统（插表 + API 对接，之前定过）

## 五、四处待确认（已定 2026-10-23）
1. **报销默认审批链**：先给一个默认（办公小额 → 1 级主管；大额 → 主管+财务+厂长），**节点可配、不改代码**（对齐 地基/审批与预警 统一引擎）；后续在配置里改。
2. **采购申请单下单前审批**：默认**四类都审**（生产物料/设备资产/行政耗材/个人报销挂单），节点按"类型+金额段"可配；**无小额免审**（同报销口径）。
3. **供应商**：默认**只登记、不评分分级**（名称/资质/结算方式/联系方式/质量备注够用）；要评分/分级走 属性标签 `供应商.等级`（自由文本+常用词提示），不建重型评分体系。
4. **应收/应付账期**：默认 **一单一配**（每单/每供应商记一个账期），不预设全局月结/现结；需要批量改的走"账期模板"配置项，不写死。

## 采购价格、入库计价与库存成本（2026-11-14，需求已确认、待实施）

### 业务边界与价格

- 物料档案支持维护**参考采购价**，记录计价单位；库存单位和每个允许采购的单位都可设置或按物料的固定换算关系建议计算。参考价可人工修改，价格可结合供应商、物料规格、颜色及生效时间区分；具体适用范围与匹配优先级实施时在任务单确定，不能凭名称猜测。修改参考价不能回写历史采购单、入库单或已记账成本。
- 采购订单选择物料、规格和采购单位后带出适用参考价，用户可修改单价与金额。数量或单价变更时计算金额，人工修改金额时反算单价；界面须清晰标注当前依据，按十进制计算并在明确边界舍入，避免浮点误差或反算精度丢失。单据保存计价单位、数量、单价、金额、币种、税务口径及实际换算快照；币种、税率、含税与不含税规则由采购和财务任务明确，不硬编码假定。
- 固定换算支持采购单位和库存单位价格换算，例如一盒 100 个：10 元/盒对应 0.10 元/个。物料上配置的换算系数仅是建议，采购及入库单可按本次业务修改，保存本次换算和两种单位数量，不修改公共单位或物料默认配置。按实际数量计量的卷等包装不能按固定系数虚构库存单价，须依据实际库存数量和对应金额计算。
- 采购入库可关联采购订单并带出单价、金额；收货有差异时在业务权限范围内允许修改，明确差异、原因和操作人，保留采购单价格与入库实际价格。单据审核、过账后的变更、退货、冲销、价格差异、发票与费用分摊通过受控业务单据处理，不能静默覆盖历史事实；应付及结算由财务规则承接，具体对账规则在采购入库开发时确定。
- 订单或 PO 选“客供＋自采”表示允许两种来源；实际收货时选择客供或自采，同一物料可分不同来源收货。客供物料需管理数量、客户归属和出入库来源，不默认记为本厂采购应付或自有存货成本；自采部分按实际业务关联采购订单、入库成本和财务应付，具体无采购单入库的权限及财务处理在收货任务中明确。

### 库存成本与批次参数

- 系统参数提供库存成本核算方式，**默认移动加权平均**；另支持**按批次个别计价**。参数的公司、库存维度、生效日期和权限边界应在成本任务中明确，不能把不同公司、客户归属或其他不应混合的库存直接平均。
- 移动加权平均：在核算范围内，入库后平均单位成本 =（入库前库存金额 + 本次计入库存的实际成本）÷（入库前库存数量 + 本次入库数量）；发出按当时适用的平均成本计价。计价使用库存单位，采购单位换算与实际入库数量、金额留快照。采购退货、退料、期初、费用调整、跨期过账、负库存和零库存等场景需单独确定规则并验证，不能简单套用公式。
- 批次个别计价：每次成本层或受控批次保存实际入库成本，发出按实际选用的成本层计价；不同进价不互相覆盖。入库批次与成本层的对应、退货回溯及成本调整在实施任务细化。
- **批次管理开关单独配置，默认关闭**：关闭时普通入库和领用不强制人工填写或选择批次，但每笔出入库、供料来源、客户归属和业务单据必须可追溯。开启时支持按批次收、存、领和追溯；批次管理与移动加权平均可以同时使用。
- 选择按批次个别计价时必须开启批次管理，并检查库存是否具备完整成本层；批次管理关闭状态不得直接启用该计价方法。切换核算方式、关闭已使用的批次管理或改变生效范围时，需要检查现存库存、未完成业务与历史账，制定受控迁移、结账及审计方案；不得更改参数即重算或覆盖历史凭证。正式会计核算、税费及启用/切换方案由负责账务的人员确认。
- **价格权限**：价格及供应商结算属于商业敏感数据，复用现有采购/财务权限与数据范围；在物料档案、选料弹窗、导入导出、API、MCP 和业务单据的每个读取与写入路径均需服务端保护，不能因人员具有物料查询权限就自动展示采购价。
- **实施状态**：上述参考采购价、采购与入库价格联动、库存计价及参数开关均为规划需求，尚未实现；订单 BOM 用料中的采购单位数量参考不是采购价格或库存成本。


## AI 沙盘相关采购、供应与成本资料（2026-11-19，规划待设计）

在现有通用采购和业务单据设计上，补充盘点供应商供货范围、交期、最小批量、报价及有效期、产能日历、质量、履约和运输信息；标签按供应商功能分类维护，结构化数值及依据保存在业务资料中。订单、BOM、库存、采购在途、客供承诺及检验记录共同支持缺料和到料预测。

沙盘应区分客供与自采、估算与已确认到货日期，并输出数据来源、缺口、成本口径和风险。AI 只生成可审查的采购建议或草稿，正式采购及付款仍按既有权限与审批执行。相关字段、计算口径和流程按采购专项设计确定。


### 供应商管理的标签分类

供应商功能规划物料供应能力、物料品类和交付能力等标签分类，可结合实际增加资质、质量特点和合作状态。标签辅助采购与沙盘筛选候选；供货数量、报价、采购周期、产能日历和到货表现由业务记录提供并标注时间与来源。AI 可基于授权的履约和质量记录提出建议，经业务负责人确认后生效。

原先“默认只登记、不评分分级”的业务约定继续有效；后续标签建议不自动建立供应商评分制度，是否采用正式评价规则另行设计。
