# 模块-财务与采购

> 版本：v1（定稿 2026-10-23，四处待确认已拍板）
> 更新日期：2026-10-23
> 说明：织云 ERP 财务模块 + 厂内采购（通用采购申请单）。地基引用 地基/审批与预警（审批/报销走审批）、地基/员工ID与工号。财务只管"钱/账"，采购申请/收货/资产入台账等动作分别归 生产/物业资产/行政 模块。

---

## 〇、边界（先定死，防巨无霸）
- **财务 = 管钱/管账**：应付、费用、报销、应收、工资、成本归集、总账对接。
- **采购/收货/资产入台账 = 各归各模块动作**，财务只"核销钱"：
  - 生产物料采购收货 → 生产流程（收货单）
  - 设备/资产采购到验 → 物业资产（进资产台账）
  - 行政办公/耗材采购 → 行政（领用）
  - 财务是"钱最终落到哪、核销给谁"，不是"管所有采购动作"。

## 一、采购：一张通用采购申请单 + 类型分流（认可"不建独立采购体系"）
**不建重型采购模块（无询价/比价/供应商评分那套），一张通用采购申请单 + `采购类型` 字段分流**（同"通用领料单"套路，不重造）：

| 采购类型 | 收货/入账动作 | 钱归 |
|---|---|---|
| 生产物料（订单耗材/面辅料） | 到料收货（走 生产流程 收货单） | 应付 |
| 设备/资产 | 到验 → 进 物业资产 台账 | 应付（资本性） |
| 行政办公/耗材 | 收货 → 领用 | 费用 |
| （个人采购 = 走"报销"，见第三节，不算采购） | | |

- 共用：申请单结构、审批流、**供应商档案**（供应商名/资质/结算方式/联系方式/质量评级）、"到没到、花了多少"登记。
- 供应商档案全类型共用一张。


> **单据"归属公司"字段**：订单/采购申请单/报销单/发货单 每张单据带一个 `归属公司`（选 品牌档案 里的一项），**开单时定、之后锁定**；打印/报表抬头、开票主体、走哪个公司账 都读它（见 前端规范 A.0"业务层"），**不随全局展示品牌切换而变**。
## 二、报销（含"个人采购报销"）

### 2.1 报销单分类（你定的"分几类"）
- 报销类型：**差旅 / 办公 / 加油 / 其他**（可加，走 属性标签 `报销.类型` 或字典）。
- **两档挂法（你定的）**：
  - 报销单上"**可选引用 采购订单 / 入库单**"（下拉选填，非必填）：
    - **引用了订单/入库单** = 这是"买东西"类，需挂申请单/采购来路 → 走"带引用"的报销
    - **没引用（空的）** = 不需要申请、不挂订单（如纯消费/加油）→ 直接报销
  - 即同一张报销单，**"引用了就走挂申请、没引用就直接报"**，不用分两种单据类型，一张单搞定。
- **实现就一句话**：报销单加两个可空外键 `引用采购订单号`、`引用入库单号`；为空即"直接报销"，有值即"挂申请报销"。系统不硬卡，引用是"可选关联"，不是前置必填（避免给报销人添堵）。

### 2.2 审批
- **不存在免审**：所有报销**都走审批**（你定的，无小额免审）。
- **审批节点可自定义**：报销的审批链（几级、谁审、按金额/类型分走哪条链）**做成可配置**，不写死。
  - 按"报销类型 + 金额段"可配不同审批链（例：办公小额 → 1 级主管；大额 → 主管+财务+厂长）
  - 审批节点增删/调序 = 配置，不改代码（跟 地基/审批与预警 的统一引擎对齐，审批地基成套定时这里挂上）

## 三、财务各块（钱/账 边界）
- **应付**：生产物料 / 设备资产 / 行政采购 三类采购的付款核销（供应商对账、付款单）
- **费用**：行政办公、水电、维修、食堂补贴、宿舍赔偿/补领、车辆油费保养 等
- **报销**：差旅/办公/加油/其他（见二），核销挂"经手人(员工ID) + 审批链"
- **应收**：客户按订单/PO 付款（代工费 + 超交/次品扣款）
- **工资**：计件/计时 + 社保（预留扣减，见 人员管理 第九节）
- **成本归集**：订单 面辅料 + 工时 + 分摊 → 订单成本
- **总账/报表**：甩外部财务系统（插表 + API 对接，之前定过）

## 四、散落的"财务预留口子"汇总（本模块统一收）
| 来源 | 口子 | 归到财务哪块 |
|---|---|---|
| 宿舍 | 物品损坏赔偿、钥匙补领费 | 费用 |
| 食堂 | 外包补贴（按就餐人数×标准） | 费用（开关，外包才生效） |
| 车辆 | 加油/保养/违法处理 | 费用（引用车辆单据，走报销/审批） |
| 物业资产 | 报修/水电/资产报废残值 | 费用 / 应付 |
| 人员管理 | 计件工资、社保扣减 | 工资 |
| 生产 | 订单成本、外协扣款 | 成本归集 / 应付 |

## 五、四处待确认（已定 2026-10-23）
1. **报销默认审批链**：先给一个默认（办公小额 → 1 级主管；大额 → 主管+财务+厂长），**节点可配、不改代码**（对齐 地基/审批与预警 统一引擎）；后续在配置里改。
2. **采购申请单下单前审批**：默认**四类都审**（生产物料/设备资产/行政耗材/个人报销挂单），节点按"类型+金额段"可配；**无小额免审**（同报销口径）。
3. **供应商**：默认**只登记、不评分分级**（名称/资质/结算方式/联系方式/质量备注够用）；要评分/分级走 属性标签 `供应商.等级`（自由文本+常用词提示），不建重型评分体系。
4. **应收/应付账期**：默认 **一单一配**（每单/每供应商记一个账期），不预设全局月结/现结；需要批量改的走"账期模板"配置项，不写死。
