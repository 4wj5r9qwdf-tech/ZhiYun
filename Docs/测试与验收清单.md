## 二、功能验收

- [ ] 需求目标、输入输出和不做范围与确认后的文档一致。
- [ ] 正常路径验证具体业务字段和值，不只检查 HTTP 状态码。
- [ ] 必填、边界、重复提交和权限不足等适用场景已验证。
- [ ] 角色和数据范围符合权限地基；敏感字段展示已核对。
- [ ] 涉及数据库时，DDL/迁移脚本可追溯，测试库结构与代码一致。
- [ ] 相关列表、统计、导出及软删除过滤口径一致（如适用）。
- [ ] 前端页面验证加载、查询、保存、错误反馈及主要交互。
- [ ] 前端页面遵循《前端规范.md》的 Ant Design Vue 组件约定和对应页面模板，不另建一套组件/样式。
- [ ] API 文档只记录已实测接口；智能体机器契约按实际能力补齐。
- [ ] 用户完成业务验收，记录验收日期和结论。
